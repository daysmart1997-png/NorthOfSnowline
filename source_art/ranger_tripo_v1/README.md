# 当前游戏主角 · Tripo 建模参考 v1

2026-09-10。用户要求以当前游戏主角为对象，以所给人物图片为精细度/展示方式参考；不替换成示例图片中的女性角色或夏装。

## 使用文件

- front.png：精修正面，全身中立 A 姿，作为主要建模参考。
- right.png：同一角色的右侧面补充参考。
- back.png：同一角色的背面与背包补充参考。

三张图各自只有一个人物，白底、完整帽顶到鞋底；不要把不同视角当成三个不同角色。图像参考不能保证自动生成结果的拓扑、骨架、材质分区和动画可用性。新模型生成后仍需接入项目现有动作、足部贴地、服装分区和人物界面。

## 设计约束

沿用橙色毛线帽/围巾、深蓝棉衣/棉裤、深色手套雪靴、橄榄灰帆布背包及底部横向毯卷。围巾短尾在角色右胸，对讲机在角色左侧；不添加武器。细化面部、衣褶、针织、帆布与皮革，保持风格化冬季巡林员身份。细化参考并非现有游戏模型的精确截图，不代表已经替换模型。
