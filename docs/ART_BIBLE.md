## 视觉目的

观察一个孤独的人，在巨大的雪原里活下去。使用明确轮廓、安静留白、冷暖对照和有来历的痕迹；有手工塑造感，但不做糖果色玩具村。正常世界具有可信的重量、厚度与天气，异常才有成立的基础。

| 类别 | 形状与材质 | 画面职责 |
|---|---|---|
| 人造物 | 厚木梁、方形开口、沉稳红褐与褪色帆布，粗糙表面 | 可辨认的休整与连接节点，不等于自动安全 |
| 自然物 | 偏向主导风向的树干/分叉、破碎岩石、连续柔软雪丘 | 将路径与遮蔽组织出来，不平均撒满所有空地 |
| 主角 | 深蓝衣服与暖色帽/围巾、清楚的背包外轮廓 | 缩到实际游玩尺寸仍可追踪；面部精度优先级低 |
| 信号设施 | 细长竖向结构、少量灯点 | 远距离辨识，未恢复设施不能因漂亮而全部点亮 |

暖光表达明确来源：炉火表示供暖，灯具表示照明，信标表示工作状态。窗口颜色不能假装整间屋已经温暖；异常暂不设一眼可识别的专用颜色。Whiteout 表现服从 WORLD_BIBLE.md，不在美术任务中加入实体穿越或掉落神秘物品。

炉火遵循同一暗炭红 → 橙金的色阶与缓慢起伏，室内将火舌限制在炉窗，露天营地才有少量火星。强度由真实剩余燃料驱动，添柴短暂变亮，火将尽时火舌/炉光/窗外暖光一起减弱；不得在空炉上保留装饰火焰。动作与光照暂停一致，见 [炉火统一](43_HEARTH_ANIMATION.md)。

## 雪的三个尺度

1. 大尺度：沿用共享地形与高低差。借光照读出坡形，不为一张图增加与物理不一致的巨型位移。
2. 中尺度：门前走道薄且踩实，小屋两侧/背风处积雪厚；树根附近有收缩与低雪唇，部分枯枝被埋。形体影响可行走表面时同步碰撞、雪深与落脚取样。
3. 小尺度：使用低强度法线、粗糙度和真实脚印。痕迹集中在人经过的位置，降低重复纹理与远处闪烁；保持雪的留白。

雪并非一个“高清贴图开关”。至少分别控制纹理世界尺度、松雪法线强度、压实抑制、粗糙度范围、雪色范围与高频细节的距离衰减。底色由项目调色主导，外部纹理不直接带入写实照片的明暗和颜色。

## 材质来源与技术选择

- 本轮选择 [ambientCG Snow004](https://ambientcg.com/view?id=Snow004) 的 1K OpenGL 法线及粗糙度。官方 [许可说明](https://docs.ambientcg.com/license/) 明确素材为 CC0，可修改与随项目分发；下载与逐文件 SHA-256 记录在 assets/textures/snow004/source.json。实际原图维度以导入检查为准，不仅凭包名推断。
- 原始下载包放本地 artifacts，游戏只携带使用的两张图。保留来源和导入配置；PNG 纳入已有 Git LFS 规则。无需为了材料球预览下载 8K 包或未用的 Blender/颜色/位移文件。
- 地面用世界坐标取样，让主地形与局部脚印网格尺度一致。法线与粗糙度按线性数据采样，使用 mipmap。法线为 OpenGL 方向，接入时明确 X/Z 轴基底，不误当成底色。
- 现有脚印高度场继续管理压痕，材质只补表面细节。浏览了 [GDQuest 的开源着色器库](https://github.com/gdquest-demos/godot-shaders) 与 [Godot 雪变形示例](https://github.com/Flynsarmy/gd-snow-project)，本轮不复制代码，也不引入一套替代地形插件。前者说明仍有 Godot 4 移植工作，不能把不同版本示例当即插即用组件。
- Shader 接口依据 [Godot spatial shader 文档](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)。当前先兼容 Windows 与 Mac 共用的渲染方式，不把更换渲染器作为精修前提。

## 制作与核对流程

| 顺序 | 动作 | 完成依据 |
|---|---|---|
| 1 对照 | 固定小屋镜头、缩放、脚印与天气参数，记录修改前画面和性能 | 可以复现，不能只比较不同光照下的截图 |
| 2 雪材质 | 接入素材，分离形状、法线和颜色，压住高频与反光 | 松雪、压实区、脚印有层次，近远网格无明显接缝 |
| 3 地面与模型 | 调整局部雪深，补树根接触、树的轮廓与少量枯木 | 物体有重量，路径仍可走，物理不脱离可见表面 |
| 4 环境核对 | 清晨、正午、暮色、夜晚、暴雪与室内 | 不靠单一夕阳隐藏问题；角色、通路与交互仍可读 |
| 5 质量与性能 | 同一设备、机位、预热和采样方式比较；运行游戏回归 | 记录均值/P95与边界，不能用静止样本宣称全程稳定帧率 |
| 6 接续 | 更新 PROGRESS 与素材来源，按实际截图记录剩余问题 | 两端能够继续，不把审美上的“满意”伪装成自动测试结果 |

复现入口：`python tools/run_visual_slice.py --godot <binary> --label after`，加 `--profile` 得到同镜头短时性能样本。原生渲染，无录像，不写玩家存档，日志截图均在 artifacts/visual-slice/。

本轮先验证以上六种正常条件；极光和 Whiteout 单独排在正常雪林成立之后，不把“七张效果图”当成已经完成的叙事功能。HUD 先保留当前可玩界面，截图隐藏 HUD 只用于观察材质，不能算已实现简洁 HUD 模式。角色轮廓、衣料和步态已接续精修，见 [环境与角色收尾](16_ENVIRONMENT_AND_RANGER.md)；灯具状态与新的 HUD 行为按后续实际优先级推进。
