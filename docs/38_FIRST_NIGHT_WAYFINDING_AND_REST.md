# 第一晚接续：雪路、休息准备与全章往返

2026-09-12，Windows；基线 30e197c，保留前两轮未提交制作。

## 本轮实现

- `settlement_paths.gd` 集中定义原木屋、伙房、柴棚、宿舍之间的旧通道。`terrain_profile.gd` 用浅压雪层和柔和路肩改变真实地面高度、雪深；不是悬浮贴花。范围限制在南侧聚落，既有脚印仍按接触表面计算。
- `arrival_world.gd` 增加四根木桩和旧布条，布条随风幅度变化。路标避开门口和通路中心，保留实体碰撞。沿用上一轮实际炉火驱动的暖窗，不添加常亮导航箭头。
- 休息页显示醒来的日期/时间、剩余饱食/水分/体温、消耗、炉火熄灭时间和覆盖所选时长还缺的木柴。食水偏低或提前醒来时提醒；三项操作并排，720p 下直接可见。
- 进食和饮水按钮沿用 `main.backpack_action`，实际消耗随身物资、更新预估，数量为零时禁用。添柴仍需要操作场景中的炉子。
- `expedition.rest_preview` 克隆实际状态运行既有休息规则，追加展示字段，不扣除玩家时间或物资，不新增存档字段。木柴提示按所选完整时长计算，即使预计会提前惊醒。
- 修复 `day_cycle.clock_text` 经小数小时转换时跨午夜少显示一分钟的问题，改按整数游戏分钟换算。

Godot 4.7.2、Windows、Compatibility，原生检查使用 RTX 3070 Ti / 1280×720。

- 新增 `preparation_check`：独立状态夹具从 23:40 开始、炉火剩 30 分钟，验证 00:10 熄灭、跨日预估不修改真实状态；真实鼠标点击吃喝、空物资禁用、实际休息结果与预测一致。原生 `PREPARATION_OK`，截图位于 `artifacts/settlement-polish/rest-before.png`、`rest-prepared.png`。该夹具不是玩家全程录像。
- 休息操作助手会先将控件滚入可见区域，再发送鼠标事件。不会通过直接发射信号绕过滚动裁切。
- `station_playtest` 新增 `--first-night-route`、`--light-pack`；先实际走到聚落领取有限食水/燃料，点炉、拿磁带机、从休息 UI 过夜，再接完整求援章节。修正离开原木屋的斜穿侧棚旧测试路线，未移除碰撞。
