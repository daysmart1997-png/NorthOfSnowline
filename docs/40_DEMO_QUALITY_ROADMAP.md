# 《雪线以北》试玩版质量路线图

2026-09-12，按用户批准的竞争力差距制定。目标是有辨识度、值得继续游玩的独立游戏 Demo；不是销量承诺，也不把自动化检查通过等同于好玩。

## 体验承诺与范围

固定高位镜头、风格化微缩雪原。一个人靠搜寻、准备与判断熬过第一晚；周岑留下的物品实际帮助玩家，磁带和无线电把求生与寻找失联者连接起来。

先打磨目标约 30 分钟的首次体验，实际长度由陌生玩家试玩决定：傍晚山口 → 首份补给 → 炭工聚落 → 有代价的过夜选择 → 音乐与安顿 → 次晨线索。已有完整求援往返保留，不以扩大地图或新增动物种类作为首要验收。后续 Demo 的正式终点、导出包装和商店素材，待首次体验验证后锁定。

## 分批制作与验收

| 优先级 | 补齐的差距 | 要做的体验 | 验收方式 |
|---|---|---|---|
| A：进行中 | 生存取舍与人物关系 | 拆挡风板换应急燃料，承担保暖损失；周岑的留言对应可实际取得的物资；次晨有能亲自观察的线索 | 选择前能说明代价；规则/场景/预估/存档一致；正常路与应急路都能继续；不靠免费奖励伪造情感 |
| B：进行中 | 统一视觉品质 | 雪面去重复、雪岩/树根/屋基交界；木/布/金属的统一尺度与粗糙度；人物与动物接地；小屋/维修间室内构图 | 同机位对照清晨/正午/黄昏/夜晚/暴雪；物体不漂浮，关键可交互物可辨，UI 不抢场景焦点；Windows 和 Mac 分开复验 |
| C | 磁带成为核心特色 | 从盒内留言发展到实际可听的叙事、停播/重播、字幕和听觉空间；音乐与行动代价共同影响探索，逐步接入重新点亮据点 | 玩家能描述磁带在体验中的作用；提示不抢危险声音；无声/字幕游玩能理解必要信息；素材来源完整 |
| D | 从阅读任务到亲身经历故事 | 简化反复纸条，加入物件状态、声音和现场变化；铺垫一次明确且克制的异常 | 不看开发者解释能理解已知事实与未知问题；不靠长段文字直接揭晓周岑位置；异常有可观察证据 |
| E | 陌生玩家可发现性与节奏 | 邀请 5～8 位未参与开发的人，分别观察首夜和求援返程 | 记录迷路、求助、无聊、紧张、退出点、结束后是否愿意继续及原因；样本是定性发现，不冒充市场预测 |
| F | 可交付试玩包 | Win/Mac 导出、首次启动、设置/音量/字幕、输入、存读档、结束页、错误与性能检查，真实玩法短片 | 全新目录运行，LFS 齐全，旧存档不破坏；逐机记录分辨率/帧时间/内存，性能目标与实测区分；录像不假冒玩家体验 |

每轮提交交接记录应说明：改善了什么玩家体验、实际改变、测试证据、剩余问题。UI 优先从场景引导与信息层级解决；新增按钮和提示需要检查正常分辨率与较大正文，不能只检查字符串存在。

2026-09-12 接续：B 批已开始，雪面梯度/重复、木布金属纹理和室内外暖光完成一次固定场景精修，见 [42_SNOW_AND_LIGHTING_STANDARD.md](42_SNOW_AND_LIGHTING_STANDARD.md)。自然/建筑交界、更多树型、人物/动物近景与 Mac 验证尚未齐备，不把 B 批标为全部完成。

同日炉火接续：三间小屋、猎人营地和新建营地接入共用动画与燃料驱动暖光，添柴/弱火/暂停/读档一致，见 [43_HEARTH_ANIMATION.md](43_HEARTH_ANIMATION.md)。后续仍优先补齐自然/建筑交界和实际游玩尺度的轮廓，不以新增地图替代视觉打磨。

## 已查证的公开参考与采用决定

查阅日期 2026-09-12；下表是筛选结果，不表示插件已安装或资源已下载。后续采用代码需记录版本/文件、保留适用许可证；采用素材需记录资源 ID、源链接、实际文件、许可、处理过程和哈希。

| 参考 | 用途与限制 | 本次决定 |
|---|---|---|
| [《漫漫长夜》生存模式](https://www.thelongdark.com/survival-mode/) | 研究玩家自行判断资源与环境风险的体验；不复制剧情、美术或素材 | 借鉴准备、出行、后果的关系，放进我们的首夜选择 |
| [DREDGE / Black Salt Games](https://www.blacksaltgames.com/) | 研究探索、获取资源、升级能力、发现秘密的连续循环 | 用“获得帮助 → 产生牵挂 → 继续寻找”组织首夜；不复制钓鱼系统或异常设定 |
| [ambientCG Snow004](https://ambientcg.com/view?id=Snow004)、[CC0 许可](https://docs.ambientcg.com/license/) | 地表细节来源。项目已有 1K NormalGL/Roughness，见 assets/textures/snow004/source.json；Snow001 也有公开 PBR 包，但换更大贴图不能解决形状/尺度问题 | 沿用已集成 Snow004，先做材质尺度和雪面重复诊断，未重复下载 |

| [Kenney 素材使用说明](https://kenney.nl/support)、[Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) | 官方资产页提供 CC0 资产；电子操作音可候选，不能把现成风格当作本游戏最终听感 | 后续声音对照库，暂不采用；现有声音仍用项目资产，未下载新音包 |

## 陌生玩家观察表

测试前说明这是开发版；不提前讲最优路线或藏物点。记录运行平台、输入方式、是否玩过生存游戏。屏幕/声音录制先征得参与者同意，不收集无关个人信息。

| 时点 | 观察 | 结束后追问 |
|---|---|---|
| 找到木屋前 | 首次食物/屋檐是否被发现，何时查看 UI，是否求助 | 什么让你决定往这个方向走？ |
| 第一次准备过夜 | 是否理解燃料有限，是否发现伙房/柴棚，是否比较拆板代价 | 当时最担心什么？为什么这样选？ |
| 磁带与暖身 | 是否主动播放、读留言，对周岑留下的物资有没有反应 | 你现在怎么看待周岑？ |
| 次晨/返程 | 现场线索是否被发现，危险声是否足够早，能否临时绕路 | 哪一刻最想继续，哪一段最想停？ |
| 结束 | 是否主动提出下一步目标 | 如果 Demo 到这里结束，你想知道什么？ |

发现多人在同处困惑时优先修改，再用新参与者复测。未来愿望单/销量表现须另行验证；当前没有此类数据。
