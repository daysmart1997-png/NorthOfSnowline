# 房屋与家具差异化 · 第一轮实现

2026-09-11，基于用户认可的 29_ARCHITECTURE_REVIEW.md 方案，在 Mac 的 a471f77 工作副本上实现。没有新增房屋名牌；通过外形、材料方向与家具功能区分小屋和维修间。

## 完成内容

| 位置 | 本轮变化 | 体验目的 |
|---|---|---|
| 护林小屋 | 保留高山墙、门廊和柴棚；床位后移、厚床垫/偏放枕头/下垂毯，替换等距毯条；混合罐、布包、茶盒、杯碗；桌抽屉/横撑/椅子；炉门、把手、灰盒、烟管接头和水壶 | 保留熟悉的归家空间，让家具看起来有人长期使用 |
| 维修间外观 | 10×8 米地板、低缓的宽屋顶、横向风化木板、长窗、封闭服务窗；线路设备外移以避开加宽的墙 | 在游戏正交镜头下，无名字也能辨别工作建筑 |
| 维修间内部 | 厚木工作台、台钳、工具托盘和底层工具箱；工具墙、零件柜、靠墙抽屉；右侧钢管折叠床和卷铺盖；中央保持通行空间 | 先看到维修区域，再发现临时休息角落，避免重复小屋的生活桌布局 |
| 联动 | 房间宽度/碰撞、炉具、床铺目标、剖切区域、室内层与木地板判定；保留户外柔化氛围与脚印隔离；维修反馈/零件盒使用模型定位点 | 避免家具穿行、交互被埋、宽房间边缘误判到室外 |

本轮没有增加新任务、资源奖励、柜门开合或坐下/躺下动画。椅子、台钳和柜子是环境模型；取暖、模块维修、床铺休息、收纳升级沿用当前生存系统。

## 资产与代码

- 可编辑源：`source_art/architecture_v2/cabin_lived.blend`、`station_workshop.blend`；来源/定向重建说明在同目录 README.md。
- 运行资源：`assets/architecture/cabin_lived.glb`、`station_workshop.glb`，保留各自 `.import`。分别约 2.32 / 1.77 MiB，36,922 / 27,206 三角面、52 / 44 个网格；未以细分全场景的方式提高面数。这里只记录资源统计，不将网格数视为实际 draw call 或帧率测试。
- `tools/refine_buildings.py` 只构建以上两套新资产与 `scripts/building_layouts.gd`，复用旧脚本的辅助定义与小屋构建段，不执行旧全量导出。原 cabin.glb、原 Blender 文件和桥梁/营地/人物资产均保留。
- 源文件保存时保留独立对象，导出 GLB 时才按组/材质合并。屋顶、前/右墙、升级组、火窗和家具语义组保留。
- 新布局表供 world_frontier.gd 的建筑选择/碰撞与 interior_view.gd 的房间宽度读取。world.gd 的剖切宽度支持每栋配置，其他旧条目沿用原默认。
- `ModuleSurface` / `ModulePickup` 是模型上的定位点，供 chapter_experience.gd 和零件拾取使用。新台面较厚，不能继续使用旧的 1.14 / 1.19 米世界高度。
- 横向木板有独立木纹方向参数，旧木材默认方向保持一致。维修间床铺交互改为右侧折叠床，外部线路设备位置与碰撞同步平移。

1. 定向 Blender 生成成功（BUILDING_REFINEMENT_OK），源和导出均存在，Godot 导入通过。
2. `python3 -u tools/run_checks.py --godot /Users/leoduan/.local/bin/godot`：import + **二十组全部 PASS**，逐项核对成功标记、断言、ERROR 与资源泄漏；最终汇总 `artifacts/architecture-review/checks-final.log`。
3. 新 `tools/building_check.tscn` 纳入统一检查：实际网格包围盒确认维修间更宽更低；正常输入走到桌椅旁、两屋炉具、无线电、维修台与折叠床，三段维修按 3/4/2.5 秒真实计时完成，再取走零件；添柴、休息一小时、床铺/收纳升级、宽房间侧边地板/剖切/墙碰撞、出门脚印通过。
4. 同一检查在 1280×720 Mac 原生窗口复验，BUILDING_CHECK_OK，无错误或退出泄漏；`artifacts/architecture-review/native-building-final.log`。测试只在两地点之间重定位，门廊及室内路线均用真实输入和碰撞；不是全章往返通关录像。
5. 原生查看维修前/测试后指针及接点、两屋火炉、折叠床，以及白天/21:00 两屋外观和室内画面。证据 `artifacts/architecture-review/walkthrough` 和 `final`，采集标记 ARCHITECTURE_REVIEW_OK。静态采集会冻结生存并设置时间/火量，等待超过 0.45 秒室内外过渡后截图，不作为真实时间体验证据。
