# 临时原木屋打磨 · 2026-09-11

承接山口＋岗亭样板，按已确认效果板第二栋继续制作。本批只改临时炭工木屋及其实体补给摆放；长期护林小屋、维修间、主线状态、食物消耗和存档 schema 保持原系统。

## 外观与内部

- 新独立低矮横向原木屋，小窗、较厚石基、宽双坡屋檐、侧工具棚和烟管，与灰绿单坡岗亭区分。保留 7.4×6.4 米房间尺寸、门口与原路径位置，不挂房屋名称牌。
- 木材与铁材各自颜色、粗糙度、法线贴图，织物共享微弱法线。实际 GLB 导入材质不走旧 Timber shader。源、导出与来源说明位于 source_art/lodge_refinement 和 assets/lodge_refinement。
- 卧铺隔挡降为低木框与帆布，床毯用连续起伏网格；炉具增加门框、炉圈、门扣与晾架，火窗仍由真实燃料状态控制。台面与下层架分开，既有床位、炉边和路线纸交互坐标保留。
- 侧棚有空旧桶和铁锹环境物件，不摆不可取用的装饰木柴。侧棚是 CutawayRight 的子结构，进入房间后随右墙隐藏，避免室外构件遮挡室内。

## 物资、碰撞与兼容

供给点仍为 lodge_stores，三根木柴显示在补给台下层，绷带和电池在台面；领取一根隐藏一根，剩余数量和已搜寻状态沿用 Expedition.supply_taken。未新增一份背包状态，也未增加免费燃料。旧存档的数量和点位身份继续适用。

ArrivalCatalog 选择新 GLB，单列侧棚立柱、外侧斜撑范围和旧桶的碰撞；低帆布隔挡高度与模型一致。旧 arrival 测试的斜穿路线经过新侧棚，已改走有余量的外侧路径，不移除碰撞来迁就旧测试。门口、房间主通路、补给桌、炉边、卧铺和便笺使用实际移动输入验证。
