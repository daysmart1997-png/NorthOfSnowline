# 第一晚：傍晚抵达炭工聚落

2026-09-12。承接玩家关于“晚一点开局、天黑前到木屋、入夜后探索食物与燃料”的建议。本轮在南侧现有地图形成四屋聚落，保留前方岗亭和后续七号护林小屋、北岭维修间。

## 玩家流程

新旅程 17:00 从山口出发，口粮仍为零，湿靴/初始体温和既有补给保持。开场改为白天走了一天、昨天约定的守听未获回应。先在岗亭找第一份食水，再进入炭工聚落。以实际连续步行、短搜寻校准：约 17:58 到达木屋。这个时间是自动路线证据；玩家搜寻、绕行或奔跑会改变到达时刻，不在进屋时强制切夜。

| 场所 | 位置 X/Z | 用途与有限补给 |
| --- | --- | --- |
| 炭工木屋 | -11 / 73 | 旧炉、可用卧铺；原有 3 木柴、绷带、电池；新旅程的磁带机移至床边 |
| 废弃伙房 | 10 / 78 | 2 份口粮、1 份水；无可用炉床 |
| 旧柴棚 | -23 / 87 | 油布下 4 根干柴；透风、不能休息 |
| 破损宿舍 | 12 / 59 | 2 布料、1 绷带、1 水；湿床不可睡，换班记录提供周岑经过聚落的线索 |

各建筑新增独立 Blender 源与 GLB、颜色/粗糙度/法线贴图、家具碰撞和室内剖切。建筑附近避开树木并整平雪下基底；院落有断旧晾衣线和半埋雪橇。木屋窗外暖光只随真实燃料亮灭，不能提前指示一座已有免费炉火的安全屋。

新阶段目标依次提示取暖、食物、留柴与休息，不设置必须搜完每间屋或强制睡觉的主线锁。木屋便笺写明伙房/柴棚/宿舍用途，地图增加聚落插图，读便笺或实际进入才显示对应信息。长期护林小屋仍在北方，不取代本轮的临时落脚点。

## 生存和时间

- `Expedition.elapsed` 仍是实际经过的游戏时间，控制燃料、物资与休息；新增 `clock_offset`，`solar_time()` 返回显示/昼夜用时间。新旅程偏移 480 分钟，从 09:00 基准移到 17:00，elapsed 仍从零开始。
- schema 8 保存偏移；旧存档缺省为零，保留原时间、物资与天气节奏。偏移非有限值或越界时拒绝恢复，不先修改当前状态。HUD、背包、休息预估、路线预估、光照和夜间失温使用同一太阳时间。
- 新旅程初段风雪从较小强度逐渐增强，夜间早段达到较强值，再逐渐减弱；钟表变晚不会使 elapsed 或暴雪进度跳过数小时。
- 新旅程步行/休息饱食消耗在每游戏分钟 0.05～0.075 之间随夜间寒冷变化；奔跑为其 1.6 倍。饱食低于 20 时室外失温再增加 15%。旧存档沿用此前消耗。室内减缓失温，燃烧的炉子才能回暖，已有热茶、融雪、衣物与休息预估继续可用。
- 两小时燃料和 1/2/4 小时休息沿用原规则。预估会显示火不足，饥渴或寒冷会使角色醒来；不自动发放过夜补给。
- `first_warmth` / `first_rest` 在已有 discovered 中记录首次暖身/至少一小时休整，UI 不维护第二份进度。

## 磁带与兼容

新旅程将已有 `wreck_player` 领取点移到炭工木屋床边收纳箱，沿用唯一 ID 和原有《余烬》及电池；旧存档仍在邮递车处。只有一个领取点，没有额外刷一台机器，已领取状态继续有效。原《余烬》的室外减缓失温效果、电量消耗和背包装带/播放交互保持，第一次在安顿后的屋里就能试听。后续邮递包裹中的《归途》和周岑故事仍在原路线。

## 验证

Windows / RTX 3070 Ti / Godot 4.7.2 Compatibility。`first_night_check.gd` 使用真实移动输入走山口、岗亭、木屋、伙房、柴棚、回屋、翌晨宿舍；领取有限物资、添柴、背包播放和休息 UI，未给角色补发燃料、食物或健康。

原生 1280×720 / 固定 60 FPS 调度：17:58 到达木屋，体温值约 58.91；分段搜寻与休息至次日 08:38，健康 100、体温值约 99.75、饱食约 64.67，余柴 1 根。固定调度是输入验证，不是性能测试，也不是陌生玩家体验时长。验证首夜暖身/休息记录、选择领取/重复领取、保存恢复和旧时钟兼容。最终日志与完整回归结果以 PROGRESS.md 为准。

首次通行检查发现伙房餐桌边缘与床边收纳箱挤占过道；模型/碰撞同步让出通道后，实际输入复验通过。初次自动检查也发现快速退出音频释放未完成，标题与第一晚工具在停播后等待驱动释放；不以进程退出码或成功打印掩盖日志警告。

本机证据：`artifacts/first-night-native.log`、`artifacts/checks-first_night.log`；真实流程截图 `artifacts/first-night/01`～`08`。`09`～`11` 是单独静态相机的外观/昼夜/剖切艺术检视，日志 `artifacts/settlement-preview.log`，不当作额外玩家输入证据。全部测试使用隔离设置，不覆盖玩家存档。
