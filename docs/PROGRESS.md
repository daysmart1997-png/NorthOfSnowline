- 固定斜俯视正交镜头、按屏幕方向移动、奔跑/蹲行、镜头缩放。
- 体温、体力、健康、饱食、水分、精力和 24 kg 负重；14 类物品、7 项配方；9 处发现地点及搜寻物资。

- 磁带机和三盘音乐：背包内装带、拖放电池/磁带、播放/停止、电量与生存增益。
- 高地、背风洼地、冻湖、过桥；雪深与海拔分开计算，深雪和上坡减速。落脚深浅鞋印、连续趟雪痕迹、降雪逐渐填平。
- 8 段 Mesh2Motion 适配动作，重做对称行走腿部轨迹，实时足部射线与双腿 IK，按坡面调整鞋底。脚步音、呼吸/喘气、白气、风声/炉火与背景配乐。
- 原创林场建筑概念图及 Blender 重建的小屋、室内、木桁架桥、帆布营地；屋顶与近侧墙切开，室内有炉具、床、桌、工具、物资架等。
- 灰蓝帆布 UI、六类物品、二维展开/收起、旧纸地图。JSON 存档兼容旧版本，保存生存、物资、探索、修缮、营地和磁带状态。

## 当前架构

| 路径 | 职责与关系 |
|---|---|
| `project.godot` → `scenes/main.tscn` → `scripts/main.gd` | 启动、输入、对象组装、HUD、交互、存档和运行时回归入口 |
| `scripts/expedition.gd` | 生存与物品规则、配方、磁带效果、营地和保存数据 |
| `scripts/world_frontier.gd` | 当前世界实现：地形、积雪、建筑导入、深雪拖痕 |
| `world_frontier → world_polish → world_expansion → world.gd` | 继承链共同提供地形网格/碰撞、局部雪面、树木、POI、建筑、拾取、天气；旧层仍在使用 |
| `scripts/terrain_profile.gd` | 基岩高度、湖面、积雪、法线、坡度的共享计算 |
| `scripts/player_ranger.gd` → `player.gd` | CharacterBody3D、摄像机、动画播放、落脚事件 |
| `scripts/grounded_feet.gd` | SkeletonModifier3D 双腿 IK 与贴坡 |
| `scripts/backpack.gd`、`inventory_slot.gd`、`item_icon.gd` | 行囊开合、类别、图标、拖放和物品操作 |
| `scripts/cassette_audio.gd` | 磁带、环境、分地面脚步、呼吸和音量混合 |
| `scripts/trail_map.gd`、`field_panel.gd` | 地图与帆布 UI |
| `assets/` | Godot 直接使用的 GLB、音频、着色器及导入配置 |
| `source_art/` | Blender 源文件、概念图、原始录音、Mesh2Motion 素材及上游说明；有 .gdignore |
| `tools/` | 建模/动画/音频制作、跨平台检查；不是运行游戏的前置生成步骤 |
| `tests/` | 纯规则检查；场景/交互检查也在 main.gd 的命令行测试入口 |

- Git 根目录设为实际游戏目录，默认分支 main；设置仓库本地 LFS，不修改全局 Git 配置。

## 当前问题与限制

1. 没有完整的正式剧情流程、存档槽 UI、音量设置或 Windows/macOS 发布包。
2. 角色造型和手部动作仍需精修；互动在按 E 时结算，未等待手接触目标。足部约 22 cm 校正范围，尚无攀爬或专门台阶动作。
3. 雪痕只改变玩家周围 24 m 的渲染网格；物理碰撞使用基础地形，痕迹不保存。冻湖不会破裂或落水；地图等高线为示意。
4. 建造使用预制营地和小屋升级；不能自由拼建，不能逐段造桥。物资容器整组搜寻。
5. UI 基于 1280×720 设计；Mac 高 DPI、不同中文字体、音频和键鼠手感需要实测。
6. 游戏实际可运行资产已包含；Python 音频依赖在 Mac 的安装/再生成结果尚未验证。Blender 脚本会覆盖目标资源，不能全部盲目重跑。
7. 玩家存档保存在项目根目录 savegame.json，仅本地；如需迁移已有进度应单独复制，不能把它纳入 Git。
8. 世界实现分布于多层继承，main.gd 也承担 UI 和测试。后续适合逐步拆分，但不要在美术任务中顺手大规模重构。
