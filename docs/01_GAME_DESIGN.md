# 雪线以北 · Demo 玩法策划 v0.2

玩法基础沿用此文。v0.3 的雪面/鞋印、动作、声景和背包改进详见 `06_POLISH.md`。

更新：2026-09-08。面向 Windows 单人斜俯视第三人称；项目暂名，可后续更改。用户提供的雪地枯树林截图为当前镜头与风格依据，详见 `04_VISUAL_DIRECTION.md`。

## 玩家体验

在漫长寒冬里，让玩家感受到出门的压力、路线选择的代价和回到炉火旁的安心。采用原创北方林区、护林员和林业铁路背景；风格化轮廓、冷暖配色、安静环境声。画面目标借鉴绘画式雪景的氛围，不复刻现有游戏地图、角色或素材。

核心循环：在小屋规划 → 携带有限物资 → 出门辨认路标 → 搜寻与权衡 → 返回恢复 → 解锁更远的探索范围。

## 第一段完整任务：最后一班电波

护林站无线电损坏，车站维修箱里可能还有备用零件。玩家从小屋出发，到北面的废弃车站取回零件，返回小屋安装并发出呼叫。

1. 小屋内学习移动、镜头和 E 交互，领到基础背包与燃料。
2. 出门后看到北方红色车站和林间木制路标。温度开始降低。
3. 在林间捡取可选木柴和口粮。携带增加重量，奔跑消耗体力。
4. 到达车站，拾取零件。可在车站火炉补充体温，但需消耗燃料。
5. 返程天气逐渐恶化。较直接的开阔地更暴露，东侧林道绕行但避风。
6. 回到起点修复无线电，完成第一阶段任务，然后可以继续生存、修缮和搜寻磁带；健康降到 0 则失败，可重试。

## 系统与取舍

| 系统 | Demo 规则 | 玩家决策 |
|---|---|---|
| 体温 | 0～100 的抽象值；遮蔽减少失温，封窗小屋缓慢回暖，火炉快速回暖 | 继续走、寻找遮蔽、消耗木柴取暖 |
| 体力 | 奔跑消耗，步行/停下恢复，耗尽后自动停止奔跑 | 赶路和保留余力 |
| 负重 | 基础装备＋任务物品＋木柴＋口粮；接近负重上限降低移动速度 | 是否拾取沿途补给 |
| 健康 | 严重失温、饥饿、缺水会持续受损；绷带或归途磁带恢复健康 | 在危险状态前安排补给与休息 |
| 天气 | 晴冷→降雪→暴雪；连续过渡、降低能见度、增加热量损失 | 根据天色与时间安排返程 |
| 物品 | 14 类物品；口粮恢复饱食与体力，水补充水分，暖身茶回暖，零件完成目标 | 补给、制作、携带与储存 |
| 修缮与建造 | 封窗、床铺、储物箱和最多 3 处临时营地，共 7 项制作配方 | 消耗材料改善后续生存条件 |
| 音乐 | 3 种磁带分别提供抗寒、奔跑节能和庇护所恢复；播放消耗电量 | 搜寻旋律并按情境切换 |
| 进度 | 手动保存/继续；保存状态、位置、天气时间和已取物品 | 中途退出后继续 |

所有数值集中于代码常量/状态中，先用于测试，之后按试玩记录调参。原型体温等均为游戏化表达。

## 关卡布局

地图约 180×240 米有效探索区域，平面可行走地形为原型；外圈岩石/山体与隐形边界封闭。

- 南端小屋：起点、无线电、温暖灯光，约 (0, 0, 15)。
- 北端车站：约 (0, 0, -165)，红色外墙和旗帜作为识别点。
- 直达路：沿旧铁路北行，视野清楚但寒风更强。
- 东侧林道：由木牌引导经过林地，路径较长，区域内降低失温速度。
- 中段补给：木柴、口粮、废弃箱子；提供探索收益。

本版扩展为 6 处探索地点和 13 个新增物资容器，详见 `05_V02_SYSTEMS.md`。完整 Demo 仍以 20～30 分钟体验为目标，尚未完成玩家计时试玩，需要事件、引导和美术叙事。

## 视角与操作

WASD / 方向键按屏幕方向移动；滚轮缩放；Shift 奔跑；C 切换蹲行；E 交互；F 吃口粮；B 背包；V 制作；M 切换播放；Tab 地图；H 隐藏/显示界面；Esc 关闭背包或暂停。背包支持点击使用及磁带、电池拖入磁带机。

人物朝移动方向平滑旋转。镜头采用正交投影、俯角 52°、水平角 35°，默认画幅参数 20 米，允许 16～30 米缩放；人物约占画面高度 7～9%。室内隐藏屋顶和面向镜头的墙体，保留实体碰撞。暂不提供自由跳跃。交互必须在距离范围内，并有视线检查。

## 美术与声音

灰蓝雪地、深蓝枯树、木栅栏、细小落雪与长阴影构成统一调色板。橙红围巾和炉火是少量暖色。角色厚棉服、背包、帽子；正式角色需保留清晰轮廓。地面采用缓坡雪堆，行走留下脚印。先做一个主角和两座建筑。

v0.2 已有原创风声、踩雪脚步、炉火和三段磁带循环音乐。正式声景继续补足呼吸、拾取、无线电与地面材质差异；磁带音乐需要更长编曲与叙事内容。

## 本轮边界

本轮仍是原生 Godot 可玩原型，已加入饥渴、精力和基础制作。暂不做战斗、狼群、联机、完整制造树、疾病、换装、大世界生成、复杂布料或真实积雪变形。

待用户试玩选择：失温压力偏舒缓还是偏严苛；路线可读性；角色与镜头距离。没有反馈前按中等难度调试。
