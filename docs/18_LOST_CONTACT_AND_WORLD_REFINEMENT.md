# 第一章「失联」与场景、动作修订

日期：2026-09-09。此文记录本轮实际实现；原始故事草案继续保留，未实现部分不可视为游戏已有功能。

## 可体验的变化

- 新旅程先显示三段可跳过的镜头：南侧封路、北岭维修站、七号小屋。镜头缓慢收近，字幕由玩家按「继续」翻页，Esc 随时跳过。生存与移动暂停，结束恢复原第三人称镜头。手记可重新打开值守簿并回看开场；读取存档不重放、不重置位置。
- 第一章统一为「失联」。值守簿建立周岑 / 北岭四失联的动机，模块交接记录区分撤离时名单和后来行踪；林与守桥人的原支线保留。
- 两种报告选择 × 三种线索状态仍有独立、固定的正常回应。确认报平安后 completed 与 radio_step=4 的含义保持，先回到世界，再次查看无线电才进入可选的旧频道。
- 旧频道按「试着听清 → 核对线路卡 → 记下线索」推进，允许收起后继续。已听原句和已核对线路卡分别记录，不重复发放；结尾明确第二章气象站区域未开放，不提供地图外假目标。
- 周岑寄给七号的包裹移到邮递车旁；「归途」标签补充人物来源。保留 hunter_pack 这个历史内部 ID、物资数量和领取状态，因此旧档已经拿走的包裹不会再出现。本轮只有标签/便笺文字和既有音乐，没有新增周岑配音、自动磁带对白尾声或已听完状态。

## 美术与物理

- ranger_refined 保留八个动作，原 Mesh2Motion 上身适配与交互源保留。加入小幅骨盆偏转和反向上身/摆臂，跑步重心起伏与摆腿抬高；继续保持左右半周期对称、相位切换和足部 IK。原动作不是本轮重新向 Mesh2Motion 上传生成。
- 鞋宽/长度缩小约 18%，高度略收；参考鞋底 0.205 × 0.328 m，足印前后轮廓同步缩小，保留雪深导致的外扩、压痕和趟雪沟。帽兜凸起环移除，肩部压片、护膝和背包包边贴合衣料，肤色降低明度。
- 重建小屋、桥与帆布营地，更新源文件与 GLB。小屋增加墙面压条、转角铁件、窗台斜撑、接收机格栅与线路卡；桥面木板有色差与嵌入钉，边缘倒角更柔和。木纹用低频风化和受距离抑制的细纹，铁件/帆布共用新的轻量表面材质。
- 新物资箱有独立箱板、箱盖、铁带、锁扣和寄送标签；可收取箱体有匹配碰撞，领取时隐藏模型并禁用碰撞，重新开始/读档恢复对应状态。原堆场的大型装饰箱仍有旧模型，尚未全资产逐个替换。
- 邮递车替换为原创 Blender 模型：驾驶室收分、车窗、车门缝/把手、后视镜、轮拱、轮胎、雨刷、格栅、保险杠和屋顶积雪。合并游戏网格、七个材质面，保留源对象。三段车身碰撞，包裹放在可达车侧；生成树保留随机数消耗，在车辆占地附近清出空间。
- 维修站增加断开的线路杆、电缆卷等识别物；南侧旧地图边界内增加封路横杆、护栏与带碰撞的落石，开场对应实际封路现场，没有扩大可探索地图。
- 修复北端维修站无线电桌与工作台缺失碰撞；家具高度与抬高后的室内地板一致。修正门框开口宽度，补门廊栏杆、储物箱/货架碰撞，桥栏杆移到实际模型位置，禁用被替换旧桌/修缮方块的隐形碰撞。
- 树下段改为沿真实粗细、缩放、倾斜的凸包碰撞；增加根颈与折断短枝、根部湿暗色。并未承诺全地图所有细枝、衣物与场景物件绝不相交。

## 实现入口与存档

- expedition.gd 唯一拥有旅程状态，schema 4。chapter_one.gd 校验可选 epilogue_step（0–3，整数；大于零须正常通信完成）；旧章节字典合并默认值，不丢原完成状态、物资和报告选择。
- chapter_panel.gd 负责主动阅读与字幕；opening_sequence.gd 仅做开场镜头与暂停，不增加生存状态。main.gd 连接新旅程按钮、旧频道入口和 UI，backpack.gd 统一手记标题。
- 重建入口：tools/refine_ranger.py、tools/build_architecture.py、tools/build_delivery_van.py。执行会改写对应源与导出文件；两台设备不要同时重建同一资产。无需安装 Blender 即可运行游戏。
- 新资产：assets/architecture/{supply_crate,station_equipment,delivery_van}.glb；源在 source_art/architecture_{supply_crate,station_equipment}.blend 与 source_art/delivery_van.blend，均沿用 Git LFS。
