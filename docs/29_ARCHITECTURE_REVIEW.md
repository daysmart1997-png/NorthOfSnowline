# 房屋与家具差异化评估 · 2026-09-11

用户反馈建筑与室内家具雷同，本轮只评估和记录方案，不重建资产。依据当前 a471f77、world_frontier.gd、build_architecture.py，以及 Mac / Godot 4.7.2 实际渲染的两屋同角度外观和室内。图片与临时采集脚本在 artifacts/architecture-review；使用隔离设置、冻结生存，无录像或实际玩家存档写入。

## 确认的原因

1. home 与 station 都由同一个 assets/architecture/cabin.glb 实例化；cabin() 的颜色参数未参与差异化。房屋尺度、山墙屋顶、窗户、门廊、柴棚与基础形状相同，station 主要附加外部线路设备。
2. 室内也是同一份模型：床、无线电桌、修理台、书写桌、三层罐子架、炉具和地毯位置相同；碰撞也按同一套硬编码坐标布置。外观雷同有实际资源层面的原因。
3. 三种桌台在轮廓上都接近薄板配四根细腿；床毯是多条等距凸条，架上罐子重复等高等距，木板色差排列规律。现有倒角、木纹、积雪厚度已存在，但在当前斜俯视镜头里，功能与使用痕迹的差异不够显著。
4. 导出按结构组/材质合并网格；家具不能假设仍是可直接移动的独立对象。改布局须同步可编辑源、导出、物体归组、碰撞、交互位置和室内剖切层，不能只在游戏里挪几块可见网格。

## 建议的两种空间身份

| 项目 | 护林小屋：长期居住、希望回来 | 维修间：工作主导、可以暂避 |
|---|---|---|
| 建筑轮廓 | 保留较紧凑山墙、门廊、柴棚 | 独立低长轮廓，考虑偏置入口/侧附工具棚，线路设备融入建筑 |
| 空间组织 | 入门落雪/挂衣，炉边生活区，床边私人角落 | 长工作台与工具墙为焦点，零件柜靠墙，折叠床放角落 |
| 桌台 | 有使用痕迹的生活桌、椅凳、保留易靠近的无线电桌 | 厚台面、横撑、台钳/接线区域，避免再复制整组生活桌 |
| 收纳 | 食物/杯碗/布包高矮疏密不同，部分柜门遮挡细碎物件 | 零件抽屉、线轴与少量空位，突出工作用途 |
| 睡眠 | 床垫有厚薄变化，旧毯垂边和偏放枕头 | 卷起的铺盖或靠墙折叠床，削弱卧室中心感 |
| 材质/光 | 灰褐旧木、少量布料，暖光集中于炉边 | 木材配少量磨损金属，窗边冷光与局部工作灯；沿用真实火炉状态 |

这是提案方向，尚未修改模型；细节取舍应以实际游戏距离看得清为准。

## 推荐实施顺序

1. 先做维修间独立的建筑轮廓与室内布局样板，护林小屋保留空间记忆；从轮廓、家具组合、主视线三方面产生区别。
2. 优先制作床、生活桌椅、厚工作台、储物柜/工具架、炉具和衣物挂点的少量可复用部件。突出用途、支撑结构与不完全对称的磨损，避免以细分面数代替设计。
3. 完成后再局部添加床毯褶皱、桌沿磨损、炉门/烟管接头、局部水渍和门口落雪；避免全表面铺同一层污渍。场景不必塞满，通道与可交互目标保持清楚。
4. 同步碰撞、无线电/模块/炉火目标、视野遮挡与存档后的室内恢复；实际走到每个目标并转身离开。以无 UI/无命名牌的同角度截图检验两屋能否辨识，再检查夜间和标准缩放。

保持无逐栋房屋命名牌的约定。材质和时代背景一致，建筑功能不同；新增家具不能堵住门口或让交互隔桌穿墙。角色、主线、生存系统和已有录制路线不在此次评估中改动。
