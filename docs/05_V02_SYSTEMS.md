# v0.2 生存、营地与奇异磁带机

本文记录 v0.2 的系统设计。规则继续适用；v0.3 的动画、录音来源、长版磁带音乐和背包交互已更新，素材现状请以 `06_POLISH.md` 为准。

## 设计意图

让探索带回的物资改变下一次出门的准备，让庇护所成为值得返回的地方。磁带机是探索奖励，也是一种需要电池维持的生存工具。每次只播放一盘，按天气、赶路或休息需要选择旋律。

## 物资与制作

背包上限 24 kg，基础装备占 5 kg。共有木柴、口粮、饮用水、布料、废金属、药草、绷带、暖身茶、电池、磁带机、三盘磁带、无线电零件，共 14 类物品。超过容量时整组搜寻不扣除场景物资，可腾空后回来。

| 配方 | 材料 | 条件或效果 |
|---|---|---|
| 绷带 | 布料 ×2 | 使用恢复 22 健康 |
| 暖身茶 | 药草 ×1、水 ×1 | 燃烧的庇护所火源旁制作；恢复 18 体温、20 水分 |
| 融雪煮水 | 木柴 ×1 | 燃烧的庇护所火源旁制作；获得饮用水 |
| 封窗保温 | 木柴 ×3、布料 ×2、废金属 ×1 | 在小屋制作一次；无火时也能缓慢回暖 |
| 修复床铺 | 木柴 ×2、布料 ×3 | 在小屋制作一次；允许休息 |
| 储物箱 | 木柴 ×3、废金属 ×2 | 在小屋制作一次；背包内存入/取出物资 |
| 临时营地 | 木柴 ×3、布料 ×3 | 室外附近有效空地；最多 3 处 |

营地避开铁轨、主要林道、河道、已有地点、陡坡与碰撞物体；包含遮蔽、床铺与可添柴的火源。进入遮蔽范围时隐藏顶棚。每份木柴提供 120 秒燃烧时间。休息推进 120 秒生存时间并恢复精力，因此仍消耗食水与燃料。

小屋、废车、猎人营地、瞭望点、物资堆场、车站共有 6 处探索地点；靠近后记录日志和地图标记。小屋门外有第一批修缮材料；西侧废车提供磁带机、余烬磁带与电池，另两盘磁带在其他探索点。

## 磁带机交互

按 B 打开背包，选磁带装入，或将磁带拖到磁带机图标。点击播放，或关闭背包按 M 切换播放；电池也可拖入或点击使用。

| 磁带 | 播放时作用 |
|---|---|
| 余烬 | 室外失温速度减少 25% |
| 步履 | 奔跑体力消耗减少 25% |
| 归途 | 在庇护所每秒恢复 0.10 精力与 0.04 健康 |

初始电量 65%，播放每秒消耗 0.13 个百分点；耗尽停播。换电池补至 100%。只有携带机器、对应磁带且有电时生效。背包暂停模拟时可以试听，同时暂停电量与增益；暂停菜单连同声音一起暂停。当前没有跟随节奏按键或演奏判定。

后续方向：让磁带承载前人留言，暴雪中断续的旋律提示隐藏地点，收集完整录音解锁新段落。先试玩现有补给、电池与增益强度，再增加磁带数量。

## 可编辑素材来源

- `tools/build_assets.py`：本项目原创几何、骨架、动作和三段短循环音乐的生成脚本。
- `source_art/ranger.blend`：可在 Blender 继续编辑的角色源文件。
- `assets/characters/ranger.glb`：实际导入的角色与 Idle / Walk / Run 动画。
- `tools/make_soundscape.py`：本项目风声、炉火与踩雪音效的合成脚本。
- `assets/audio/`：上述脚本生成的 WAV，未使用商业歌曲或外部采样。
- `assets/shaders/`：本项目雪、树皮、织物与鞋印材质代码。

本轮没有使用 Mesh2Motion 下载动作；后续可按开发路线替换或扩充动画。
