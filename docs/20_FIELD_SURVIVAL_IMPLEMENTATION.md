# 生存、行装与野生动物：实施记录

2026-09-09—10，Windows / Godot 4.7.2 / Blender 5.2.1 LTS。接续 [19 设计提案](19_SURVIVAL_AND_CHARACTER_DESIGN.md)。本轮实现第一章可用的系统，不扩建第二章，也不把首次 25–40 分钟目标当作已测得时长。

## 现在可以做什么

- 新旅程从小屋南侧封路附近开始。连夜出行后：饱食 35、水分 30、体温状态 68、精力 70、雪靴湿度 35%。应急食水仍在背包。旧存档保留原数值，不套用新局状态。
- 饥渴低于 35 降低体力恢复，低于 20 进一步降低恢复并减慢步行；原基础消耗不加倍。按普通活动公式，10 分钟不补给约剩饱食 18.8、水分 4.2。气温、伤情、冲刺和暂停需要另外考虑；这不是无补给真实通关测时。
- B 行装增加人物页：可旋转并播放待机动作的实际 3D 角色、衣着/身体视图、六个部位入口。衣物有独立实例，记录湿度与完好度；探索取得的新帽、手套、防风外套和雪靴可穿戴。备用旧衣可拆成布料，避免永久积累无法减负。
- 换装保持旧衣与总负重，不复制道具；保暖、挡风和湿度影响室外失温。深雪行走使靴/裤更容易潮湿；屋内行走不会再被室外雪深浸湿。炉边可分段烘干，布料可修补破损衣物。
- 身体状态包括受寒、伤口、扭伤、食物不适和呼吸道刺激。动物实际命中造成伤口与衣物破损，明显跌落可扭伤，受寒/冷空气有相应反馈。绷带止血、夹板处理扭伤、药包处理适用不适，处理后逐步恢复；没有万能即时药草回血。
- 原有喘息保留，新增有间隔的咳嗽/动物警告合成声；关键状态另有文字提示。声音为原创程序合成，不是动物或人物专业录音。
- 森林中有鹿、狼，西北侧远离主路的区域有一只熊。鹿警觉后逃离，狼与熊有感知、追踪、警告/攻击前摇、恢复与脱离。听觉受移动速度与风雪影响，生肉气味受固定世界风向影响，视线由物理遮挡判断。室内保护与统一暂停生效。
- 原创四足模型保留 Blender 源，头部和四肢可独立驱动。动物有轻量程序步态与警戒显示，雪地留有成对小足迹；足迹仅为限额视觉痕迹，不是动物长期追踪存档。
- 小屋急救盒、周岑备用衣袋、猎人工具卷、维修站衣柜与护林器材箱给出物品来源。林道增加指路木牌；主路与东侧绕行保留，不强迫击杀动物才能推进故事。
- 已有鹿尸与猎获动物可分批取肉，每份半千克、10 个世界分钟。取完肉后可取生皮；烹饪、处理皮革与加衬衣物成为制作链。生肉有气味与保存时间，主动应急生食明确提示会引起不适；变质生肉不能继续烹饪。
- 小刀近身使用；猎弓蓄力、实体箭矢逐段碰撞与回收；猎枪射线命中、弹药、装填与较大范围枪声。Q 切换，按住右键瞄准、左键使用，R 装填。镜头保持原固定斜俯视。
- 维修站模块增加清理接点、固定接线、测试三步，完成后仍通过原有拾取和剧情面板取得模块。步骤进度存档；原六种正常通话与可选旧频道不变。没有额外强制吃饭/打猎门槛。

## 时间、存档与取消

`Expedition` 继续拥有背包与全部生存状态，新增 `FieldKit` 保存衣物实例、装备槽、部位状态、动物/尸体余量、武器选择、肉品时间与模块步骤。`FieldExpedition` 负责真实世界动物、射击、耗时操作和提示；人物页只发起规则操作。

schema 5 增加 field_kit。旧 schema 4 缺字段时赋予原造型对应的基础装备，不重置旧健康、资源或剧情。新增字段验证在赋值前完成；拒绝错误槽位、未知状态、非有限数值和无效实例。落地箭与飞行中的箭均随状态保存；飞行物恢复位置、速度与已飞行时间。猎枪装填状态在读档后需要重新装填，不重复扣弹药。

查看/比较、剧情与暂停菜单保持世界暂停。确认烘干/修补/制作/取肉后回到世界，按现有比例推进时间：10 世界分钟为 10 秒活动。移动或 E 中止，材料在完成时核对并结算；已取完的小份肉保留，未完成段不生成物品。暂停保留正在执行的段，读档重新开始未完成段；模块已完成的步骤保留。

制作前检查火源、材料、负重和足够燃料；完成时再检查条件。寒冷或动物伤害会打断手工操作。火炉保暖、衣物烘干与“归途”磁带共用真实燃火判断，无火屋不能靠磁带回血。

## 资产与界面

- 新角色源 `source_art/ranger_equipment.blend` 从已精修 ranger_refined 源派生，不覆盖旧角色；按部位分材质，导出合并蒙皮网格，保留八段动作。当前换装使用同版型的区域配色/衣料与规则差异，未制作每件衣物独有的剪裁几何。
- `tools/build_equipment_ranger.py` 可单独重建这一角色；`tools/build_wildlife.py` 单独重建鹿/狼/熊。所有 `.blend` 与 `.glb` 沿用 LFS。
- `assets/ui/field_paper.png` 和 `field_canvas.png` 为内置生图工具生成的无字材质。人物详情/剧情采用纸页，行装采用暗帆布与缝线，正式字与按钮由 Godot 渲染。来源见该目录 README；没有将概念图整张铺成假界面。
- 原背包分类、制作、存放、磁带拖放与手记保持可用。人物图稿中的装饰引语与袜衬槽没有带入游戏。当前服装页为可用简化版，未完全复制图稿的服装热点连线、纸边轮廓与独立物品插画。

## 验证入口

`tools/run_checks.py` 增加 field / hunting 两组：前者覆盖衣物状态与重量、部位治疗、旧档迁移、操作取消/结算、取肉持久化、三步模块、人物页和暂停；后者在真实物理世界中验证箭矢命中与回收、弹药/装填、墙体遮挡、狼的感知到攻击、进屋保护和暂停。

原室内/探索/剧情检查将模块预设为已测试，继续单独检查原拾取/交互与房间；三步模块另由 field 检查。旧“归途”检查明确点燃炉火，符合修正后的规则。新出生点不应让旧室内检查默认人在屋内。

实际检查结果与最新截图路径以 [PROGRESS](PROGRESS.md) 顶部为准，不把旧日志混称本轮通过。视觉检查必须包括人物正面、身体页、短/长中文剧情、动物近景与正常游戏视角；Windows 通过不代表 Mac 已验证。

## 边界

这是第一章的可玩生存扩展；没有第二章新区域、复杂狼群生态、专业四足动作捕捉、每件衣物独立网格、医学级病程或完整枪械动画。野生动物感知是有限规则，固定风向与简化避障并非通用导航系统。首次玩家通关时间、动物密度、物资数量与声音听感仍需实玩校准，不能声称已经最终平衡。

本轮不录制视频、不写玩家实际存档、不提交或推送。两台设备后续通过正常 Git/LFS 流程同步。
