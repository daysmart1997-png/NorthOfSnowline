# 第一章流程 1–4 · 探索、返程与声音

用户于 2026-09-11 授权：按房屋优化后的流程做到顺序 4，玩家试玩暂停，完成后上传现有 GitHub 仓库。本轮同时交付此前尚未提交的两屋差异化模型；以本文和 PROGRESS 顶部为当前交接依据。第一章候选版和 Windows 独立验收不因此自动完成。

## 1. 当前版本收尾

- 在新房屋模型下，从新游戏实际走到小屋补给、维修间、三步修模块、添柴/休息、返程、无线电求援；基线完成约 509 秒模拟时间。该预定路线用于发现阻断，不代表普通玩家的章节时长或陌生玩家测试。
- 加厚台面上的维修反馈和零件使用导出定位点；交接纸页也改为跟随零件盒高度，避免落到盒盖里面。床铺、柜体与门廊通行继续纳入检查。

## 2. 可选择的探索

- 维修间新增可搜寻零件柜：按 E 持续操作 1.6 秒，移动可取消；仅有木柴 ×1、布料 ×1。领取成功后柜门打开、柜中物资消失，柜体和碰撞保留，不作为新的大补给点。
- 奖励仍使用 Expedition.loot 与 collected，背包满不会领取或记为搜过；重复搜寻、存读档不刷新。新游戏恢复关闭/有物资，旧档无需新字段。柜中便笺收入手记，提醒一份柴可添火，也可在已有炉火旁融雪。
- 小屋增加空挂钩痕迹和一只旧手套，靠近查看出巡前纸条；保留字幕式阅读、重读、暂停和手记。它只证明周岑出发前的准备，不确认他现在的位置，错过不影响求援。
- 林道已有布条随当前风雪程度摆动；第一处布条可观察避风线索。持模块返程、实际风雪增强、走近岔路时才记录一次“返程时的布条”。不伪造刚刚有人经过，不添加房屋名称牌或满屏高亮。

## 3. 求生路线选择

- 交接单和手记的返程入口提供铁路、林道、西岭三种步行估算，显示当前木柴/饮水、约需时间、体温值和水分值消耗，以及需先补给提示。
- route_planner.gd 克隆当前 Expedition，沿明确的路径采样，调用同一 speed_factor、地形移动修正、tick、windbreak/shelter 规则；不改玩家时间、物资或状态。估算不自动喝水/休息，也不模拟新的动物遭遇或搜寻时间，途中可以改道。
- 没有为了制造紧张调高失温或伤害。实测示例：当前时间 16:00、体温/水分均 65，铁路约 132 游戏分钟、失温约 32；林道约 172 分钟、失温约 38。林道有约 72 秒采样行程处于避风区，但绕行与后续天气可能抵消收益，界面明确说明。新遭遇与补给停留另算，不能将表格当作存活保证。
- 原有营地、添柴、融雪、湿衣烘干与休息继续承担补救作用；不增加任务硬门槛或自动替玩家选路线。

## 4. 故事回应与声音层次

- 如果发现出巡前纸条，报告时增加对应回应；求援成功与周岑下落未确认仍分开表达。无线电正文可以重读，阅读暂停生存。
- 新增原创合成的柜门摩擦、纸张/杯底轻响音效，由 tools/build_exploration_audio.py 定向生成；没有下载或录制他人声音，无新增第三方素材许可。
- SnowWind 子总线送往 SnowEffects，室内外平滑切换低通频率（约 900/11000 Hz）并保留原有风量渐变；暂停跟随游戏，效果音总音量/静音仍生效。
- 炉火按玩家到当前火源的距离衰减，阅读时再降低；近处狼/熊警告会短暂压低磁带和背景音乐，原有方向音源继续保留。新游戏/加载清除危险压低计时，暂停不消耗计时。
- **本版交付文字与音效，不含演员或合成人声对白。** 已发现的 Fal 语音服务返回未登录，未生成/收费/上传内容；按既定“人声素材未准备时先完成文本、触发和声音层次”的安排推进。后续人声可按 departure_trace、radio_step 2–4 接入，保留现有文本与暂停/重读，不阻塞本轮。
