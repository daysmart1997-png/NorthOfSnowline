v0.3 更新：实际起伏雪面、局部鞋印顶点凹陷/隆起边缘/降雪覆盖、不同冠幅与粗细的树形和积雪枝干、8 段重定向动作、柔边呼气白雾、帆布卷背包。当前实现与边界详见 `06_POLISH.md`；以下保留初始方向依据。

用户于 2026-09-08 提供雪地、枯树、脚印、栅栏与小人物的画面。依据可见特征确定方向；仅凭单张图不能断言原作品的相机具体参数，以下是本项目实现参数。

## 画面构成

- 斜俯视正交相机，52° 俯角、35° 水平角，跟随角色；滚轮只改变画幅。
- 人物为较小的深色轮廓，橙红围巾作为视觉锚点。角色细节以这个观看距离判断，不把近景毛孔当成目标。
- 雪地使用灰蓝色、缓慢起伏和柔和明暗；树干与岩石为深蓝灰。
- 枯树有不对称枝杈，低角度方向光形成长阴影；阴影是构图的一部分。
- 少量小雪粒、足迹、被雪压住的岩石和木栅栏提供尺度与行走痕迹。
- 大部分画面让给环境；HUD 缩小，H 可隐藏；暂停时自动显示菜单。
- 房屋内切掉屋顶、前墙与右墙的显示，碰撞保留。前景植被遮挡的进一步淡出列入后续打磨。

## 当前实现与后续

当前在真实 Godot 场景中实现相机、枯树、缓坡地形/碰撞、长阴影、脚印、栅栏、落雪与房屋剖视。v0.2 加入雪地细纹、树皮与朝上积雪材质、织物细纹、柔边鞋印和火焰粒子。人物已替换为原创 Blender 骨骼模型，包含衣缝、围巾、背包和靴子，播放 Idle / Walk / Run 动画。

后续继续增加手工场景与树种，优化脚滑和坡面贴合、交互手部对准；保持当前镜头下的轮廓清晰。v0.3 已采用 Mesh2Motion 官方动作，在本地 Blender 适配原创角色。

不要以截图的水印、品牌或原作 UI 为资产制作目标。项目继续使用自己的名称、任务、地图和资产。

`artifacts/demo-preview.png` 是当前项目的真实引擎截图，隐藏 HUD 以方便比较风格；不是概念图。最终观感仍需人物、关卡资产和声景打磨。
