# 返程风险与维修间路线图

2026-09-12 / Windows / Godot 4.7.2 Compatibility。

## 制作内容

- 维修交接页的铁路选项明确提示西侧狼活动；东侧林道说明绕行与避风。估算仍只模拟衣物、地形、天气和步行消耗，明确排除搜寻时间及动物袭击，不承诺林道安全。
- 新增 `return_guidance.gd`，在维修间外和旧桥南侧各放一个有实体木桩、木纹、积雪顶边、赭色布条和几何绘制箭头的路牌。附近返程提示每处只出现一次；必须实际查看告示才写入手记。路线选择不会封锁其他通路。
- 维修间西墙的旧路线图悬于现有储物柜上方，以旧纸、木框、钉头和褪色轨道/绕行线条增加工作场所细节。薄挂件不侵占地面过道；继承车站室内可见层。靠近可查看补给、辨路和途中改道的说明。
- 活着的熊/狼在玩家室外、未进入警戒且相距约 6～18 米时，按真实位置提供东/西/南/北声音提示。暴雪会缩短提示距离，沿用已有空间音效和音乐压低。不会凭提示提高动物警觉或修改生命。
- 每只动物 45 秒间隔、全场提前提示 12 秒间隔，避免附近动物叠加播报；暂停不推进，重开/读档重建动物时清空临时冷却。死动物、鹿、室内玩家不触发该提前提示。原视线/听觉/气味、追赶、攻击前摇和伤害保持。

## 验证

- 原生 RTX 3070 Ti / 1280×720 / 固定 60 FPS 调度：`RETURN_GUIDANCE_OK`。实际输入接近维修间墙图、岔口木牌，查看写入手记、隔离存读档；返程选择未溢出。检查动物提前提示在损伤前出现、暂停/死亡/室内排除以及防止同时提示。独立定位夹具不当作完整旅行证据。
- 已查看墙图室内、交接页面与岔口截图：`artifacts/return-guidance/01-workshop-board.png`、`02-return-choice.png`、`03-junction.png`。日志 `artifacts/return-guidance-native-final.log`。其后交接估算提示补回“搜寻”排除说明，最终回归覆盖该文案。
- 两条 headless 固定 30 FPS 的完整输入路线包括山口、有限领取、第一晚、次日维修与回家求援。铁路 `STATION_COMPLETE`，第二天 17:24、健康 31.01、体温值 73.99；少取一份口粮/一根柴的林道 `STATION_COMPLETE`，第二天 17:59、健康 100、体温值 71.86。两条均验证经过两个提示区，report 均 complete。日志 `artifacts/return-guidance-route-direct.log`、`return-guidance-route-sheltered.log`；报告在 `artifacts/return-guidance/route-direct/` 和 `route-sheltered/`，未覆盖上一轮记录。
- 铁路脚本沿预定路径继续前进，不会因为收到提示主动避敌。因此较低生命说明路线仍有危险，不代表已验证陌生玩家能理解并成功退避。固定调度不是帧率性能测试；本轮未录像。
- 完整回归及仓库审核见 PROGRESS.md 顶部。首次回归在交接页检查发现原“搜寻不计入估算”说明遗漏，恢复该说明后重新运行全套。

## 接续与限制

本轮是风险表达和室内场景细节，不是维修间整体模型重建。继续保留此前本地未提交模型、源码、导入设置；没有下载素材、重建旧 Blender 资产、新增二进制或变更存档结构。未提交、未推送。Mac、实际声音听感、陌生玩家首玩及性能专项仍待验证。下一步先试玩收到提前声音后从铁路转向东侧是否自然，再做维修间与长期护林小屋的材质统一、照明层次和生活细节。
