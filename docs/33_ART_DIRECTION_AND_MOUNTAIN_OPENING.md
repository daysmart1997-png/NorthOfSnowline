## 现状诊断

- 新两屋仍调用 tools/build_arrival_assets.py 的同一个 shell；窗带、门框、墙板处理近似，临时木屋与长期小屋都读成木墙＋双坡顶。应先拉开屋顶、体量、入口和附属空间的差别。
- world_frontier.gd 按材质名统一覆盖材质；Timber/Floor 使用 timber.gdshader。该着色器主要用正弦生成木纹、统一高粗糙度，没有构件 UV、端面、局部掉漆与专属磨损图层。只精修 Blender 材质，导入后可能仍被旧覆盖逻辑替换。
- field_surface.gdshader 用同一 wear 方式处理几种表面。布、漆层、锈蚀需要分别建材质，不能只靠 metal 开关。
- 项目已有 ambientCG Snow004 的 1K NormalGL/Roughness，来源记录在 assets/textures/snow004/README.md。先沿用轻微雪粒细节，重点修改积雪轮廓、雪岩交界、材质尺度及光照。
- south_pass.gd 当前是多块石体和护栏，构图更像小路障；terrain_profile.gd 的南侧没有与穿山经历相符的山体关系。start_new 当前仍带一份口粮；去掉口粮必须同时验证首次补给可发现性与整章食物总量。

## 美术方向与配色

目标：克制的手绘风格三维生存场景，大形体清楚、材质有磨损、低饱和冷色环境和少量生活暖色。以下是项目自己的调色起点，不声称是某商业游戏的原始参数。

| 用途 | 基色起点 | 表面处理 |
|---|---|---|
| 积雪 | #DCE5E6 | 粗糙、低强度微法线；薄边、厚雪檐与风塑坡体分开 |
| 雪影/远山 | #879DAF | 随实际光照变化，远景降低对比；不烘焙固定太阳阴影 |
| 岩石/铁炉 | #37464E | 岩石大切面与细裂缝；炉具另用磨损金属 |
| 风化木材 | #70645A | 顺纹、端纹、渗水痕和有限色差，避免规则长条明暗 |
| 岗亭漆层/搪瓷 | #596B65 | 哑光旧漆、局部露底；漆层本身按非金属处理 |
| 锈红/帆布点缀 | #9C5944 | 只给少数门框、工具袋和主角围巾，控制面积 |
| 点火后的暖光 | #D4A36A | 由火炉/灯具状态驱动，空屋不凭空冒烟亮灯 |

制作样板先准备六类共享材料：风化木、旧漆、锈铁、粗石、帆布、雪。每类最多先做两种变化。颜色/粗糙度/法线/AO 各司其职；可收集物品的局部细节在背包近看时再增加。

## 四栋建筑：按用途改变结构

| 建筑 | 主要轮廓与材料 | 内部/物资/生存作用 |
|---|---|---|
| 废弃岗亭 | 窄高箱体、偏置单坡铁檐、灰绿掉漆、破窗、侧边小雨棚 | 值班桌、文件格、长凳；少量应急口粮/布料/水；无炉无床 |
| 炭工木屋 | 低矮厚重原木墙、偏置矮山墙、石基、外置弯烟管、侧柴棚 | 灶具与工作区、靠墙睡铺；燃料/炭袋/旧手套；能临时过夜但补给不全 |
| 护林小屋 | 高山墙、较深门廊、厚石烟囱、低饱和赭色门窗点缀 | 生活区、工作台、固定储物与无线电；可长期整备，不自动补满库存 |
| 北岭维修间 | 低长工业体、宽门、屋顶采光带、灰抹灰/旧砖下墙、镀锌屋顶 | 工作台/工具/零件/油布，休息角局促；少量生活补给，服务主线维修 |

不加房屋名牌。先做同相机的纯灰/剪影比较，即使去掉颜色也应能区分四栋；其次检查门口、窗、烟囱、屋檐积雪与地基相接。更多小杂物不能弥补轮廓雷同。

## Image → Blender → Godot 的具体交付

1. **效果图**：先确定实际斜俯视角下的四屋轮廓和山口构图，再为单栋准备前/侧/背及剖面参考。效果图不作为已经完成的游戏截图。
2. **Blender 样板**：先精做一栋岗亭，建真实门窗洞、屋檐厚度、错位板件和不规则积雪；切顶/遮挡组、室内通路、碰撞和交互定位一起制作。高处山体先用不同轮廓的可复用山脊块，避免锥体复制。
3. **材质制作**：木纹按构件方向展开 UV；大面积墙/屋顶共享贴图，端面和小物用图集。Blender 程序材质需要转成可交付贴图，或在 Godot 明确重建对应着色器，不能假设复杂节点经 GLB 自动等效。先用 1K 共享纹理，确有近看需求再用 2K。
4. **Godot 对照**：保留 Compatibility。为新资源设置明确材质槽和映射，避免旧名称规则吞掉新材质；StandardMaterial3D/轻量 ShaderMaterial 按用途选。纹理法线采用 OpenGL 方向，常用材质先验证木/漆/铁/雪在阴天、晴天、夜火三种条件的区别。
5. **样板通过后扩展**：同游戏分辨率与镜头并排比较概念/灰模/运行截图；确认形体和材料都成立，再扩到其他三屋和六类物资。实际门口穿行、剖切、室内外隔离和脚印仍须复验。

## 物资系统：保留状态基础，改善摆放与反馈

继续使用 Expedition 和 ArrivalState 的容量/有限库存/放置/存档事务。改进资源数据，区分物件的材质、尺寸、握持/开启位置、声音类别与出现环境；不另建背包状态。

- 物品依用途摆放：食水在生活处，干柴在背风干燥处，电池/零件在工具或无线电附近。避免四栋房子都在同一张桌上摆同样礼包。
- 保证首个食物来源，剩余可选点以固定种子做有限变化；不是一上来随机不给食物。废弃处可有空容器，但首轮不能连续空搜。
- 当前水按份消耗；永久水壶/液体容量是后续独立规则批次，不能只有空壶模型而没有容量与存档联调。
- 动画/声音应匹配动作：布轻放、铁碰木、纸袋开启分别处理；每件优先一段可信短反馈。尚不把通用手部 IK、全部装饰可拾取或刚体搬家纳入这一美术样板。

## 雪山开场与求生节奏

移除近处人工路障式山崩展示，改为三层山地关系：远处连绵山脊、中景错落山肩、近处可走的曲折雪道。玩家沿山间小路出来，转弯才看到树后岗亭的屋檐/电线杆；之后从纸条和生活痕迹推断下一处落脚点。开场镜头不提前把安全屋逐栋展示给玩家。

- 山口仍放在现有南侧扩展区域，先重排已有路程；远山主要承担背景尺度，不先扩大整张世界。
- 固定斜俯视下，相机一侧的山肩降低/退开；山峰在远侧，山路保持可见。坡度、转弯半径与碰撞按现有无跳跃角色的能力制作，雪接触继续由真实地形判定。
- **初始随身口粮为零，但饱食值不归零**；保留少量饮水、衣物及必要工具。初始数值先按现有消耗跑路线，不直接给用户承诺几分钟必达。
- 首个压力是“食物用完、衣服湿冷，需要找到人类活动痕迹”。第一处保证可发现的一份食物与可用补给；吃后能继续赶路，不补满全部状态。
- 提供主路线与短支路，让玩家作出一次补给/时间取舍；不能用不可见倒计时或立即饥饿掉血代替探索。
- 找到有炉木屋，才首次面对“添火休息还是继续走”；找到护林小屋后接续无线电和寻找周岑。
- 需要同步 opening_sequence、main 新游戏/提示、chapter_one 开场/任务/回忆文字、路线纸与全章验证，避免画面已换山口而文字仍反复描写眼前山崩。旧存档不重置物资或传送角色。

## 查证过的制作参考（2026-09-11）

- [Material Maker](https://github.com/RodZill4/material-maker)：程序纹理制作和模型绘制工具。适合生成本项目自己的木纹、漆层、布纹及粗糙度；不是现成的同风格美术包。仓库默认 MIT，具体外部预设/素材仍看各自来源。
- [GDQuest Godot Shaders](https://github.com/gdquest-demos/godot-shaders)：包含交互雪、风格化火和纹理混合示例。README 仍提示 Godot 4 迁移，因此只选取算法参考；未在本项目验证过即用兼容性。
- [Walter Palladino shaders](https://github.com/walterpalladino/godot-shaders)：包含按法线覆雪、三向投影、分层地形与 UV 上雪/苔层示例。可研究雪岩交界与覆盖方法；尚未下载或接入，不能将演示效果视为本项目达成。
- [Godot StandardMaterial3D 文档](https://docs.godotengine.org/en/stable/tutorials/3d/standard_material_3d.html)：核实粗糙度、OpenGL 法线和三向投影等基础。三向投影优先用于无明显方向的石/雪；木板用有方向的 UV。不依赖 Compatibility 不提供的次表面散射。

本轮没有安装 Material Maker、下载第三方资源包或移植上游代码，保留当前已记录的素材来源。本项目配色、建筑组合和开场节奏属于本次设计建议，不是上游仓库结论。
