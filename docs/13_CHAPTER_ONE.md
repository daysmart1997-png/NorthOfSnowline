# 第一章 · 最后一班电波

2026-09-09，Mac / Godot 4.7.2。原“取零件 → 修复即完成”任务扩展为可玩的章节叙事初版。以下内容已经实装。

## 章节弧线

1. **没能发出的平安报**：山崩截断下山路。初始菜单与 HUD 给出求援动机；在小屋无线电前按 E 阅读值守簿，知道谷口频道与北岭备用模块。没有必须等待固定时刻的通信门槛。
2. **沿途有人经过**：岔路路线纸、旧营地纸页串起送药的“林”与守桥人。雪橇货单指向西岭收信簿。线索要主动查看，允许跳过或乱序发现。
3. **留给后来的人**：成功取得模块后展示交接记录。末班车取消、人员撤离，模块留给后来者求援。背包装不下时不会触发剧情。模块与交接单在当前导入桌面的空处，拾取一并收起。
4. **返程取舍**：铁路直接且迎风，林道较远但避风，可选绕访西岭取得两人平安到达的回条。时刻、体温、木柴、饮水和风险提示固定在按钮上方。选择记下打算，不锁路线、不奖励虚拟属性，可在手记调整。天气、暮色、失温和行走共用原有时钟，没有突然加暴雪。一次性危险提醒随存档保留。
5. **真正的回应**：安装模块 → 报告位置 → 报告发现或先询问下山办法 → 谷口回应 → 玩家确认后完成。收信簿、仅营地纸页、尚未查明三种信息状态有不同回应；不强迫收齐线索。回话时冻结报告依据，通关后补查线索不会改写先前通话。

本章结束“谷口知道这里还有人”的目标，以北坡信标未亮留下下一章伏笔。下一章尚未开放，结束页与手记明确说明。之后可继续生存、修缮和探索。

## 表现与状态

- 房屋不挂命名牌。值守簿、交接单、帆布与收信簿使用少量原生几何体和现有材质；没有重建 GLB / Blender。西岭书页放在独立支撑物上，不随补给箱隐藏而悬空。
- 共享冷灰蓝面板、暖色强调和中文阅读列。长记录滚动，风险提示不随正文滚走；阅读暂停生存与移动，Esc 收起。完整记录、当前推断与结尾回应进入手记。
- 无线电有原创程序生成的短电流声，接入 SnowEffects 和总音量；实际可见的指示窗随修复改变。本轮为文字交互，没有人物配音。
- scripts/chapter_one.gd 集中六条记录、目标、手记推断和通信规则；scripts/expedition.gd 是唯一状态所有者。state schema 3 增加 chapter，外层存档 version 仍为 2。
- scripts/chapter_panel.gd 只展示状态并调用规则；main.gd 负责交互、暂停与灯窗；backpack.gd 展示手记。
- 各个通信步骤可手动保存：Esc 收起阅读面板，再 Esc 打开暂停菜单保存。没有新增自动覆盖玩家存档的检查点。中断后在无线电前按 E 续接。
- 旧已完成存档迁移为已确认状态，不要求重做。坏数据或与完成标志矛盾的步骤，在修改当前状态前拒绝。新游戏清空章节进度。
