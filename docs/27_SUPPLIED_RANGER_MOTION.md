# 新主角与自带动作适配 · 2026-09-10

用户提供新的 Tripo GLB，包含放松站立、行走、跑步，要求更新游戏主角并适配其他动作。

## 角色与动作

运行入口 `player_ranger.MODEL` 改为 `ranger_supplied_v3.glb`；人物界面复用同一入口，所以世界与人物页同步。保留用户原始 11,000 三角面、41 骨骼及蒙皮；缩放至 1.88 m、统一方向和兼容骨骼名、运行图集降至 2K，分出六个服装区域并保留脸部/围巾原色。原有换装染色和湿衣反馈继续有效。

| 游戏动作 | 来源与处理 |
|---|---|
| Idle | 自带 standing_relax，保留约 17.58 秒完整放松序列 |
| Walk | 自带 walk，选完整单周期 1.167 秒，去除线性平移并对齐左脚接触 |
| Run | 自带 run，选完整单周期 0.625 秒，去除线性平移并对齐左脚接触 |
| CrouchIdle / CrouchWalk | 本地 motion_v2 重定向，匹配新腿长与踝高 |
| Pickup | 新放松姿态为底，屈膝俯身，单手向低处伸取 |
| Interact | 新放松姿态为底，双手伸向操作台高度 |
| Consume | 新放松姿态为底，手抬至脸前再放下 |

每段循环仅做短接缝过渡，不把自带走跑重做成旧程序步态。原动作参考平移速度（米制）约为 Walk 1.269 / Run 4.624 m/s；播放速度随实际移动速度同比变化，避免两周期误当一周期或重复根位移。游戏角色移动仍由碰撞体控制。

`play_action()` 现在按实际片长与播放倍率计算持续时间，避免旧的一秒上限截断动作。移动可打断交互；继续沿用原来的脚步、足部贴地、积雪脚印、呼吸和保存规则。

## 源与检查

原文件、可编辑源、制作报告和来源说明在 `source_art/tripo_supplied_v3/`；重建工具 `tools/adapt_supplied_ranger.py`，只读测量工具 `tools/inspect_supplied_motion.py`。旧模型未覆盖，未上传外部服务。

角色回归保留真实输入下的走/跑/蹲与停走检查，新增原地姿态不漂出碰撞体、Idle 原长度、拾取下蹲、手到嘴边/操作高度。原先要求两腿完全镜像的旧程序动作断言，改为新动作的抬脚/接触方向/循环连续性与交替落脚验证，允许用户动作本身的自然不对称。资产检查核对原始面数、41 骨骼、蒙皮归一化、2K 图集、六部位衣着和八段动画。

坡面回归由“所有时刻相对静态骨骼都近乎水平”改为“地形修正不能大幅偏离该帧原动画”，原动画自然蹬地不再被误判。grounded_feet 记录修正前旋转供该断言核对，不改变原有 IK 求解。

Windows 验证结果见 PROGRESS.md 本轮条目；实际分相截图位于 `artifacts/ranger-finish/supplied-v3`，不录视频、不写玩家存档。动作接物目前是适配角色体型的目标位置，尚未按任意桌面高度或可拾取物体位置动态计算手部 IK；此轮没有新增持枪/拉弓专用骨骼动画。
