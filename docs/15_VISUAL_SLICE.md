# 小屋雪林美术样板 · 第一轮

日期：2026-09-09。方向与流程见 [ART_BIBLE.md](ART_BIBLE.md)。本轮在当前可玩地图中实施小屋周边视觉优化；未扩大章节地图，未实装新叙事。

本页保留首轮过程；后续树冠、晨昏阴影、衣料与角色步态已进入 [环境与角色收尾](16_ENVIRONMENT_AND_RANGER.md)。当前状态以 PROGRESS.md 顶部为准。

## 已做的内容

- ambientCG Snow004 两张 1024×1024 原始贴图：OpenGL 法线与粗糙度，约 5.96 MiB。地面与屋顶使用同一来源，保留各自强度；主地形与局部脚印网格使用同一世界坐标尺度。颜色仍由项目控制，不采用照片底色；线性数据、mipmap 与各向异性过滤，避免用高分辨率原图替代风格设计。
- 地面默认纹理尺度 3.5 m、法线强度 0.22；松雪保留细节，薄雪与脚印压实区域减弱。冰面沿用原有材质逻辑。屋顶法线强度 0.14，保留已有模型厚度与轮廓；更强的初稿在暮色下显脏，已降低。
- 新增 `cabin_snow_site.gd`，集中小屋背风积雪与六棵近景树的位置；两侧屋檐、后侧和雪路两旁形成约几十厘米的积雪变化，中央约 3 m 宽的通路保留薄雪。厚度进入共享 Terrain.height/snow，地形网格、碰撞、雪深与足部取样共同变化；不添加只在 Shader 中隆起却无法踩到的独立雪丘。
- 树木改为共同主导风向加个体偏差，收小外露根部、略埋入雪面，保留不同树型。树皮积雪改为连续低频变化，去除细碎随机斑点；厚枝上保留渐细雪袖。现有全局树木的生成位置不改，新近景树使用独立随机状态，避免影响既有物资布置。
- 用 Blender 单独制作倒木、树桩和柴堆。`source_art/cabin_dressing.blend` 保留可编辑的独立木段，三个 GLB 各合并为一个 mesh / 三个材质面；附简单碰撞，放在小屋通道两侧。它们目前是环境陈设，不提供额外可搜刮资源。未运行历史全量建模脚本，未替换原小屋、桥梁或角色二进制。
- 夜间略提高冷色环境补光；限制室内炉具与灯光照到所属房间和人物，消除炉光穿墙照亮屋外雪面的现象。暖色门廊光点对齐模型已有灯具，不把窗户亮度当成供暖状态。灯具燃料系统尚未新增，现有照明与生存炉火继续分开。
- 新增固定机位六条件原生渲染/性能工具和 `visual_slice` 回归。检查工具自动创建 interior、chapter、exploration 本地输出子目录，修复新设备缺少测试目录导致保存失败的问题。

## 复现

```sh
python tools/run_checks.py --godot <Godot executable>
python tools/run_visual_slice.py --godot <Godot executable> --label after
python tools/run_visual_slice.py --godot <Godot executable> --label after --profile
```

游戏需要的 PNG、GLB、导入配置和源模型都留在仓库；运行不需要重新下载 ambientCG、安装 Python 制作依赖或执行 Blender。仅在明确修改这组模型时运行 `blender --background --python tools/build_cabin_dressing.py`，它只重建本轮三个道具及对应源文件。

对照条件为 1280×720、镜头 size 27、同一地点和脚印，涵盖 06:00 清晨、12:00 正午、17:30 暮色、23:00 夜晚、正午暴雪及夜间室内。另增加 09:00、正常 size 20 镜头与 HUD 的 gameplay.png 检查。部分截图隐藏 HUD 只为观察美术，不是新 HUD 功能。录入位置/时刻的工具截图不等于正常输入全程试玩。

性能工具为原生强制绘制、关闭 VSync、预热 2 秒后采样约 6 秒的静止外景。测试时不同时运行其他 Godot 检查，记录均值/P95/绘制调用；不把此短样本宣称为全地图帧率。
