# 弓箭反馈与 HUD 修复 · 2026-09-10

用户试玩发现右键瞄准无反馈、底部文字重叠、背包快捷键重复，并要求修复后上传 GitHub。

## 实际改动

- 持弓时圆形准星随鼠标移动，旁边显示箭数；无箭改为警告色。右键蓄力收圈并填充外环，左键放箭后重置，松右键取消。Q 切换已拥有武器。
- 预计弹道为细虚线，终点小圈标记当前预计碰撞；遇动物、树木/建筑实体或地面结束。实际箭矢有 0.28 秒淡出尾迹，最多 96 段。
- 箭矢从渲染帧移到物理帧，位置为 `p + v*dt + 0.5*g*dt²`，随后更新速度。默认物理帧 60 Hz，预测同一步长，最长 5 秒，每段检测真实碰撞，最多每秒重算 30 次。伤害、箭数经济、存档和回收保留。
- 原创合成 bow_draw.wav / bow_release.wav 提供木弓张力与弦响/破风。独立播放器共用已有 SnowEffects 总线。实际发射才响放箭声，暂停、切换或松开瞄准停止拉弓声。
- 删除 field.status 重复文字层和闲置武器/背包帮助；取肉/工作进度经 context_text() 交给主交互行。右下仅按需显示负重，完整快捷键在暂停页。
- 通知、交互、进度与生存状态分别定位；底部位置随画布尺寸更新，通知/交互可换行，调整字号与行距。HUD 文字不阻断鼠标射击。

## 验证与限制

Windows / Godot 4.7.2 Compatibility：导入与十六组回归通过，日志 artifacts/aim-full-checks.log。新增 tools/aim_check.tscn 检查蓄力与声音、预计/实际落点误差小于 0.025 米、暂停/地图/切换/无箭、扣箭与 HUD 区域不相交。旧 hunting 继续覆盖动物命中、一次伤害、回收、飞行存档和障碍遮挡。原生检查另包含真实右键/左键输入路径。
