# v0.3 细节打磨记录

本轮继续保持用户提供的斜俯视雪林方向，重点是触感、动作、声景和背包操作。下面均为实际接入功能，不是效果设想。

## 雪与树

雪面使用真实起伏地形与碰撞，保留门口、桥面和轨道的可通行性。角色附近有 24×24 米的细分雪面，鞋印通过高度纹理压低顶点，包含鞋底凹陷、压雪暗部和挤出的边缘。深浅由当地雪厚、负重、步行/奔跑/蹲行决定；深雪也会稍微降低移动速度。

脚印最多保留 180 枚，平静天气下逐渐消退，暴雪加快填平；移动时会将附近脚印重绘到新的局部区域。建筑木地板与桥面不压雪，露天营地仍使用雪地脚步。存档继续保留 v2 结构；读入旧位置与旧营地时会适应新版地表高度，脚印不保存。

树木增加弯曲分段、根部、不同树干粗细与冠幅、细分枝和枝上积雪；包含浅色桦树与深色枯树轮廓。阴影分辨率提高到 8192，并缩短有效距离改善近处边缘。

边界：鞋印凹陷属于局部渲染形变，物理碰撞使用基础地形，并未逐枚重新构建凹坑碰撞；没有挖雪、雪崩或全地图永久变形。树木仍是可调程序化资产，尚未逐棵手工雕刻。

## 动作

从 Mesh2Motion 官方 human-base-animations.glb 选取 8 段动画，在 Blender 内根据现有角色比例重定向并烘焙：Idle_A、Walk、Sprint、Crouch_Idle、Crouch_Walk、PickUp_Table、Interact、Consume。运行时对应 Idle / Walk / Run / CrouchIdle / CrouchWalk / Pickup / Interact / Consume。

角色源文件为 `source_art/ranger_motion.blend`，游戏实际使用 `assets/characters/ranger_motion.glb`。脚步声和脚印共用步态落脚事件；播放速率随实际移动速度变化，停下或暂停时停止落脚。蹲行动作已用真实髋膝动作替换整个模型下移。

拾取、火源和无线电交互有短动作反馈，移动可打断动作。当前交互仍在按下 E 时结算，没有等待手部接触目标的事务动画；拾取使用桌面拾取动作的适配版本。烘焙时调整支撑脚高度，但尚无运行时双脚 IK 和所有坡面的精确脚掌贴合。

## 声音

- 踩雪：8 个真实录音变体；另有 8 个柔化的深雪版本、4 个冰雪版本和 4 个原创木地板落脚音。避免连续重复样本，使用轮换声道保留上一脚的尾音。
- 呼吸：由真实疲劳录音处理得到轻呼吸和喘气；随奔跑、体力、寒冷变化，恢复时逐渐平复。寒冷室外伴随柔边白气。
- 配乐：80 秒原创低强度背景音乐；三盘磁带更新为各 48 秒的分层旋律。播放磁带时背景音乐渐弱，避免两段音乐争抢。
- 背包：展开/收拢时有短布料摩擦声。所有音频峰值与时长记录在 `artifacts/audio-quality.json`，导出无削波。

仍需用户通过耳机/音箱试玩判断最终音量、呼吸音色与疲劳节奏；本轮没有将音频波形检查当成完整听感验收。原创木地板、风声与炉火仍可继续替换为更丰富的实录素材。

## 帆布卷背包

按照野外装备做成带缝线、皮革边缘的帆布工具卷：展开约 0.34 秒，文字稍后淡入；收拢先隐去内容，再合上。开合全程暂停生存和移动，可中断收拢重新展开。是界面展开动画，未实现三维纸张卷曲物理。

物品分为全部、食水、医疗、材料、装备、磁带；显示类别数量、选中状态、负重条与物品用途。储存按钮依据所在位置、储物箱和库存启用。右侧磁带机拖放区持续可见，筛选磁带后也能直接拖入，不需要切回全部物品。空分类和不可用操作有明确状态。
