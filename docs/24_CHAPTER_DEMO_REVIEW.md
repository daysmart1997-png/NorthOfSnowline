# 第一章 Demo 整体评估 · 2026-09-10

本次评估依据当前脚本、章节设计、进度记录与此前渲染检查。此次没有重新完整通关、没有进行耳机/扬声器主观试听、没有取得首次玩家数据；以下把代码事实、体验风险与设计建议分开。本文是优化提案，不表示新增功能已实现或已授权整轮制作。

## 目标与总体判断

让玩家愿意为了一个人的消息走进雪地，也能判断什么时候应该回家。

当前已有可闭合的第一章：封路 → 小屋准备 → 车站模块 → 选择返程 → 正常求援 → 可选旧频道。物资、生火、衣物、伤情、野生动物、昼夜、足印、手记与保存都能承载这段旅程。主要工作应转向人物情感、决策可读性、动作/声音反馈与起伏节奏；继续增加系统前，先验证这一趟是否让首次玩家产生牵挂、取舍与完成感。

## 三个具体问题

### 一、压力在首个傍晚集中到来

`day_cycle.gd` 中一天为 1440 秒有效活动、开局 09:00，16:30 开始暮色、19:00 入夜。因此无休息跳时情况下，450 秒（7.5 分钟）进入暮色、600 秒（10 分钟）入夜。`expedition.gd` 的风雪在 90 秒后增强，于 450 秒达峰并持续一段时间，两者正好叠加。

这是代码计算，不是本轮通关计时；阅读暂停不计入这些分钟，休息会改变世界时间。不同熟练程度的玩家会在同一压力时刻处于不同地点。

建议先记录首次玩家到达小屋、离屋、营地、维修间、取模块、返家的有效活动时间，再决定是延长首日准备窗口、缓和天气变化还是调整补给。天气始终由一套真实状态驱动：不为剧情按钮突然把暴雪设到最大，也不因取到模块自动生成必经敌人。

### 二、读条不等于维修体验

模块已经有“清理接点、固定接线、测试发射模块”，但代码中三步的主要差异是标题与状态计数，各自 8 秒，期间反复播放同一交互动作。

建议让玩家先看到问题：接点结霜/氧化或导线松脱；操作后看到其被处理；测试时指针、状态灯和声音给出一次明确结果。操作可以很简单，重点在因果和反馈。门前添柴、取肉等也用不同的短反馈，但不必每类都做小游戏。

### 三、听见“有人回应”的价值尚未充分发挥

正常通话内容已经承认玩家探索结果，并保留求援成功；旧频道也没有取代本章完成条件。当前表现主要是文字面板和约 0.3 秒噪声样本，背景配乐则持续循环并依场景调音量。

建议优先制作一次可审阅的小型声音演出：按键/接通、短暂空白、清楚的一句回应、松开按键、室内自然声回落。保留阅读节奏控制与字幕，不让音频自动推走文字。旧频道随后由玩家选择是否收听。先完成这个节点及一盘人物化磁带，再评估是否需要全章配音。

本次未试听完整混音，因此不判断现有某条音乐“难听”或具体频段不合格；空间位置、触发条件和循环方式是代码可确认的部分。

## 推荐制作顺序

1. **让角色与交互可信。** 三个核心移动动作 → 转向/停步 → 鞋底/脚印/声音对齐 → 模块三步反馈。既有动画导入讨论继续等待合适的动作源。
2. **校准一趟远行。** 保留主路/避风/可选高地，优化开局第一口水与第一次取暖的指引，调整压力窗口，补一处有实际回报的探索发现和返程中的环境变化。
3. **补人物与声音。** 一段关于周岑的日常线索、一盘可选人物化磁带、一次完整求援声音节点；返家时承接真实炉火、天气和探索结果。
4. **做发布收尾与陌生玩家验证。** 保存路径/安全节点/恢复、文字可读、音量和输入；用统一路线与场景条件测两端性能，再交给未熟悉路线的人玩。

本章暂缓新增大地图、更多武器/动物种类、复杂技能树、大量制作配方、全章配音和第二章区域。复玩先来自不同路线、证据与补给决策；任意随机化关键线索会破坏叙事校验。

## 验收方式（建议，尚未执行）

邀请 3–5 名没有看过开发过程的玩家，以同一候选版本独立玩；不录屏也可通过同意后的观察记录、事件时间和游后问答完成。样本用于发现问题，不宣称统计意义上的普遍结论。

| 问题 | 观察/问答 | 不成立时先改什么 |
|---|---|---|
| 是否知道为什么出门 | 开场后让玩家用自己的话说目标 | 信息顺序与人物细节 |
| 是否知道下一步能做什么 | 标记持续找不到食水、无线电或路口的片段 | 物件轮廓、交互提示与首次教学 |
| 是否作过主动取舍 | 记录至少一次路线、负重、取暖或放弃可选点的理由 | 风险/回报可见性与替代路线 |
| 生存失败是否能理解 | 玩家能说出状态恶化的原因与补救 | 主要原因提示、反馈和恢复窗口 |
| 是否记住一处地点或人物 | 游后不提示地名，让玩家描述 | 环境线索区分度和人物留言 |
| 求援是否有完成感 | 问“这一趟改变了什么” | 回应、演出回落和持久反馈 |
| 是否愿意继续调查 | 问下一步想知道什么，而非强迫选择北行 | 旧频道证据与周岑关系 |
| 动作/声音是否影响操作 | 记录滑步、怪姿势、无法判断危险方向的反馈 | 动作速度/落脚、空间声音 |

主线/可选路线时长应由这些行程记录得出。25–40 分钟仍只能是待验证目标，不用加长读条或强制收集来满足数字。自动化测试继续保证规则、状态和保存正确，动态自然度与求生/探索意愿需要另行验收。
