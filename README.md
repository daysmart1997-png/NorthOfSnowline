# 雪线以北 · 地形与林场建筑版 v0.4

这是可在 Windows / macOS 接续开发的 Godot 源码仓库。先安装 Git LFS 并克隆，执行 `git lfs pull`，再用 Godot 导入根目录的 `project.godot`。关卡在运行时生成，按 F5 查看完整场景。

Codex 开始工作先读 [AGENTS.md](AGENTS.md) 和 [当前进度](docs/PROGRESS.md)。环境配置、首次上传、Mac 克隆与双端协作命令见 [开发说明](docs/DEVELOPMENT.md)，大型资源策略见 [资产清单](docs/ASSETS.md)。

当前 Windows 工作副本位于 `D:\GodotProjects\NorthOfSnowline`；本机桌面快捷方式仍可使用，但不进入仓库。Mac 可选择任意可写目录，不需要复制 Windows 依赖、缓存或快捷方式。

原始版本已验证 Godot 4.7.2 的 Windows 编辑器运行；最新改动已在 Apple M2 / macOS 26.5.2 上通过导入、九组检查和实际图形运行，Windows 拉取后仍需复验。尚未制作独立发布包。Mac 可双击根目录的 `启动游戏.command` 开始试玩，或在 Godot 中导入 `project.godot` 后按 F5。

v0.4 原始内容：高地、背风洼地与冻湖；按雪深、坡度和落脚计算鞋印与趟雪沟痕；对称步态及足部贴坡；依据原创概念图在 Blender 重建小屋、室内、桁架桥和营地；统一帆布界面、字体和旧纸地图。详见 [本轮内容、源文件与验证](docs/07_FRONTIER.md)。上一轮的真实脚步、呼吸、喘气和音乐继续保留。

最新 Mac 优化：门外薄雪支持连续脚印、柔化深雪拖痕、改善雪面接缝和风纹；HUD、行囊、地图及菜单统一为简约单色风格。设计规范见 [DESIGN.md](DESIGN.md)，实际检查与限制见 [本轮说明](docs/08_SNOW_AND_UI.md)。

最新探索优化：减少并细化路标、移除房屋命名牌；新增雪橇与纸页线索、休息风险预览、接触后结算和声音/生存栏设置。封窗仅减缓失温，火炉才能回暖。[玩法、性能与完整往返验证](docs/12_EXPLORATION_AND_SURVIVAL.md)。

## 开始探索

从护林小屋出发，搜寻门外补给并修缮庇护所。北岭车站有无线电零件；途中可探索废车、猎人营地、瞭望点和物资堆场。西侧废车藏着奇异磁带机，其他地点还有不同旋律。修好无线电后可继续生存。

背包容量 24 kg；体温、饱食、水分、精力都需要照顾。炉火与封窗保温有实际作用。

现已加入基础昼夜：早上 09:00 出发，现实 24 分钟对应游戏一天，太阳方向和明暗随时间变化。夜间更冷，及时回庇护所生火；休息可选 1 / 2 / 4 个游戏小时，并预览炉火和补给消耗。右上查看时间与天气，菜单和行囊会暂停计时，存档保留当前时刻。详见 [昼夜与光照](docs/09_DAY_CYCLE.md)。

| 操作 | 按键 |
|---|---|
| 按屏幕方向移动 | WASD / 方向键 |
| 奔跑 / 蹲行 | Shift / C |
| 搜寻、添柴、工作台、休息、无线电 | E |
| 吃口粮 | F |
| 背包 / 制作 | B / V |
| 播放或停止已装入磁带 | M |
| 路线地图 | Tab |
| 镜头缩放 | 鼠标滚轮 |
| 隐藏/显示界面 | H |
| 关闭背包 / 暂停菜单 | Esc |

点击背包物品查看和使用，也可以把磁带或电池拖到磁带机上。建造页可封窗、修床、制作储物箱和搭建临时营地；营地选择附近有效空地，尚无自由拼建。在小屋制作储物箱后，可以存取物资。

背包打开时暂停生存时间，可以试听音乐；返回游戏后播放消耗电量并产生增益。暂停菜单会暂停声音。

存档位于本项目的 `savegame.json`，兼容旧版；物资、发现地点、修缮、营地、储物箱、磁带与电量均保存。鞋印与沟痕最多保留 240 条记录，会随降雪消退，不写入存档。本轮开发前备份为 `artifacts/before-v04.zip`，自动测试使用独立测试存档。

### 第一章叙事初版

靠近小屋无线电按 E 查看值守记录。到车站取得模块后，选择返家路线或可选西岭调查；回到无线电前完成通话和确认，才结束本章。阅读可按 Esc 收起，完整记录保存在 B → 探索手记。想保存时，收起阅读界面，再按 Esc 打开暂停菜单保存。当前为文字交互与电流声，尚无人物配音。详情见 [第一章叙事](docs/13_CHAPTER_ONE.md)。
