# 第一章交互短音 · 2026-09-10

本轮由 `tools/build_chapter_audio.py` 使用标准 Python、确定性噪声、正弦/衰减包络原创合成，未引用外部音频样本、未使用真人或克隆人声。沿用仓库尚未另行开放许可的原创素材约定，不添加 CC0 标记。

- contact / wire / test：清理接点、固定接线、完成仪表测试。
- radio_connect / radio_received：通信接通与收到确认；它们是机械/信号短音，不是语音。
- tape_button：展开内页时的机械按钮短音。
- pack_rustle：进入庇护所时的轻微衣料响动。

全部为单声道 22050 Hz、16 位 PCM WAV。运行只需已导入 WAV；重制仅运行上述专用脚本。背景配乐与磁带音乐继续使用原有素材；本轮只改变触发窗口与淡入淡出。主观耳机/扬声器混音验收待人工完成。
