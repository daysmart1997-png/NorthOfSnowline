# Field UI surfaces

2026-09-09. Generated for NorthOfSnowline with the built-in image_gen tool; no third-party photo assets. The tool does not expose/return an independently verifiable model version. No API fallback was used. Original outputs were copied without image editing.

- `field_paper.png`: square, blank, warm gray ivory notebook paper; fine cellulose fibers, matte, very low contrast, no writing, border, folds or objects. Prompt requested base color around #DED6BD and a uniformly lit reusable UI surface rather than medieval parchment.
- `field_canvas.png`: square, flat dark desaturated navy-gray cotton canvas; finely woven matte fabric, very low contrast, no seams, folds, text, border or objects. Prompt requested color around #253844 and a reusable winter expedition material.

`scripts/field_theme.gd` uses these as StyleBoxTexture backgrounds. Runtime tint quiets the cloth; native text, controls, layout and 3D character remain separate. PNGs use Git LFS and `.import` settings are preserved. No open-source license is added to the project by these notes.
