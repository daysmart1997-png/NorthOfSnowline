Only the unmodified 1024×1024 OpenGL normal and roughness PNGs from the official 1K-PNG archive are included. The game uses them as linear surface data with mipmaps; colors and snow geometry remain authored in this project. No NormalDX inversion or albedo texture is used.

The public download URL, archive SHA-256, file sizes and per-file SHA-256 values are recorded in source.json. The source archive and unused maps remain in ignored local artifacts and are not runtime dependencies. These PNG files use Git LFS.
